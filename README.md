## ✍️ 작성 규칙

- **파일명**: `YYYY-MM-DD (N)주제.md` — 날짜순 정렬을 위해 날짜를 앞에 둡니다. 날짜는 **수업일(배운 날)** 이고, 같은 날 여러 개면 `(1)`, `(2)`처럼 번호를 붙입니다.
- **이미지**: 전부 `attachments/` 에 모읍니다.
- **이미지 링크**: 표준 마크다운(`![](../attachments/파일명.png)`) 형식을 씁니다.
  위키링크(`![[파일명.png]]`)는 **깃허브에서 렌더링되지 않습니다.**
- **정리 완료 표시**: frontmatter에 `til: v2 수업일`이 있어야 정리된 파일입니다.

> `복습_확인질문.md`의 `![[파일#제목]]` 임베드는 옵시디언 전용 문법이라 깃허브에서는 링크 글자로만 보입니다.
