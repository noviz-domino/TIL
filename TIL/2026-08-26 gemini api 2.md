## 1. 먼저 잡고 간 기본기 — 함수도 하나의 "값"이다

Function Calling을 이해하려면 이게 먼저 필요했다.

### 괄호가 있냐 없냐로 완전히 달라진다

```python
def hello():
    return "안녕"

hello        # 함수 그 자체 (아직 실행 안 함)
hello()      # 함수를 실행함 → "안녕" 이 나옴
```

```python
print(hello)      # <function hello at 0x...>   ← 함수 자체
print(hello())    # 안녕                          ← 실행한 결과
```

### 딕셔너리에 함수를 넣을 수 있다

```python
d = {"인사": hello}      # 괄호 없음 → 함수 자체를 저장
```

```python
d = {"인사": hello}      # 아무것도 실행 안 됨
d = {"인사": hello()}    # 딕셔너리 만드는 순간 함수가 실행되고, 결과값이 저장됨
```

### 꺼내서 실행하기

```python
x = d["인사"]     # 꺼내기 (아직 실행 안 함) → x 에 hello 함수가 들어감
x()               # 실행 → "안녕"

d["인사"]()        # 위 두 줄을 한 줄로 붙인 것
```

**주의**: 딕셔너리에 `"인사"`라는 키를 넣었다고 해서 바깥에 `인사`라는 변수가 생기는 게 아니다. 반드시 `d["인사"]`처럼 딕셔너리를 통해서 꺼내야 한다.

### 대괄호와 소괄호의 역할이 다르다

```python
TOOL_FUNCTIONS["get_product"]("A100")
#            ↑ 대괄호: 꺼내기    ↑ 소괄호: 실행하기
```

리스트는 `lst[0]`처럼 숫자(인덱스)로, 딕셔너리는 `d["키"]`처럼 글자(키)로 꺼낸다. 문법 모양(`[]`)만 같고 안에 넣는 게 다르다.

## 2. Gemini 스트리밍 응답

### 왜 필요한가

지금까지 방식은 **AI가 답을 다 만들 때까지 기다렸다가 완성본을 한 번에** 받았다. 답이 길면 그동안 화면엔 아무것도 안 뜬다.

스트리밍은 **AI가 글자를 만들어내는 순간순간을 조각조각 받아서**, 타이핑되듯 바로 보여준다. ChatGPT/Gemini 화면에서 답변이 좌르륵 나오는 게 이 방식.

### 제너레이터로 원리 흉내내보기

```python
import time

def local_stream():
    chunks = "안녕하세요! 스트리밍 응답입니다."
    for chunk in chunks:
        time.sleep(0.5)   # 데이터가 늦게 도착하는 상황을 흉내
        yield chunk

for chunk in local_stream():
    print(chunk, end="", flush=True)
```

- 문자열도 `for`로 한 글자씩 꺼낼 수 있다
- `end=""` → print가 자동으로 넣는 줄바꿈을 없애서 옆으로 이어붙임
- `flush=True` → 출력을 모아뒀다 내보내지 말고 **즉시** 화면에 뿌리라는 뜻 (없으면 뭉쳐서 나옴)

### SSE (Server-Sent Events)

일반 HTTP는 "한 번 묻고 한 번 답받고 끝". SSE는 **연결을 끊지 않고 열어둔 채로 서버가 조각을 계속 흘려보내는 방식**. `stream=True`를 주면 Gemini가 이 방식으로 응답하고, SDK가 그걸 파이썬 객체로 변환해준다.

### 실제 스트리밍 코드

```python
stream = client.interactions.create(
    model=model,
    input=prompt,
    stream=True,      # ← 이것만 추가
    store=False,
)

text_parts = []

for event in stream:
    if event.event_type == "step.delta":
        delta = getattr(event, "delta", None)
        if getattr(delta, "type", None) == "text":
            text = getattr(delta, "text", "")
            if text:
                text_parts.append(text)
                print(text, end="", flush=True)
```

- `stream=True`면 결과가 완성된 답 하나가 아니라 **이벤트 여러 개의 흐름**이 된다
- `"step.delta"` = "글자 조각이 새로 왔다"는 종류의 이벤트. 나머지(시작/종료 알림)는 무시
- **`getattr(객체, "속성이름", 기본값)`** — 그냥 `delta.type`이라고 쓰면 `delta`가 없는 이벤트에서 에러가 난다. `getattr`을 쓰면 없을 때 에러 대신 기본값(`None`)을 돌려준다. `os.getenv("이름", "기본값")`과 같은 발상의 객체 버전.

### 조각 합치기

```python
full_text = "".join(text_parts)
```

`"".join(리스트)` → 리스트 안 문자열들을 사이에 아무것도 안 넣고 이어붙임. 화면엔 이미 실시간으로 보여줬지만, 전체 텍스트를 변수로 갖고 있어야 나중에 쓸 수 있어서 필요한 단계.

## 3. Function Calling

### 문제 상황

AI에게 "A100 상품 재고가 몇 개야?"라고 물으면 **AI는 답할 수 없다.** 그 정보는 우리 데이터에만 있으니까.

그런데 우리한테는 `get_product()` 같은 함수가 있다. **이 함수를 AI가 쓸 수 있게 해주자**는 게 Function Calling.

### 핵심 제약: AI는 함수를 실행할 수 없다

AI는 우리 컴퓨터에 접근할 수 없다. **AI가 할 수 있는 건 "이 함수를 이런 값으로 불러줘"라고 말하는 것뿐**이고, 실제 실행은 우리 파이썬 코드가 한다.

여기서 "우리"는 사람이 아니라 **우리가 짠 파이썬 코드**를 뜻한다.

### 전체 흐름 5단계

```
① 우리 → AI :  질문  +  "쓸 수 있는 함수 목록(설명서)"
② AI → 우리 :  "get_product 를 {"product_id": "A100"} 로 불러줘"
③ 우리       :  실제로 그 함수를 실행 → {"name": "무선 키보드", "stock": 12}
④ 우리 → AI :  그 결과를 다시 보냄
⑤ AI → 우리 :  "무선 키보드는 39,000원이고 재고가 12개 있습니다"
```

**AI가 두 번 등장한다.** 처음엔 "뭘 불러야 할지 판단", 마지막엔 "결과를 사람 말로 정리". 그 사이 실행은 우리가.

---

### ① 설명서 만들기 (그냥 딕셔너리)

파이썬 함수를 AI에게 그대로 보낼 수 없다(AI는 파이썬을 모른다). 그래서 **글로 쓴 설명서**를 보낸다.

```python
get_product_tool = {
    "type": "function",
    "name": "get_product",
    "description": "상품 ID로 상품명, 가격, 재고를 조회합니다.",
    "parameters": {
        "type": "object",
        "properties": {
            "product_id": {"type": "string", "description": "조회할 상품 ID. 예: A100"}
        },
        "required": ["product_id"],
    },
}
```

- `"description"` → **AI는 이 설명을 읽고 "언제 이 함수를 써야 하는지" 판단한다**
- 질문할 때마다 매번 같이 보내야 한다 (AI는 기억을 못 하니까)

### ② 질문 + 설명서 보내기

```python
interaction = client.interactions.create(
    model=model,
    input="A100 상품의 재고를 알려줘.",
    tools=[get_product_tool],      # ← 이 줄만 추가하면 됨
    store=True,
)
```

`client.interactions.create(...)` = Gemini에게 요청을 보내는 함수. `tools=`는 그냥 매개변수 하나 더 추가하는 것뿐.

**`tools` 없이 물으면** AI가 그냥 글로 답한다. **`tools`를 주면** AI가 "이건 내가 모르는 정보네, 마침 쓸 수 있는 함수가 있네" 하고 **글 대신 "함수 불러줘" 요청**을 돌려준다.

### ③ AI의 요청 꺼내기

```python
for step in interaction.steps:
    if step.type == "function_call":
        print(step.name)         # "get_product"
        print(step.arguments)    # {"product_id": "A100"}
```

`interaction.steps` = AI가 답을 만드는 과정의 단계들 목록. 그중 `type`이 `"function_call"`인 것만 골라낸다.

**steps 안에 든 건 딕셔너리가 아니라 객체**라서 `step["name"]`이 아니라 `step.name`처럼 **점(`.`)으로** 꺼낸다.

**왜 `step.name`이 `"get_product"`인가**: AI가 지어낸 게 아니라, **우리가 설명서 `"name"`에 써서 보낸 그 글자를 그대로 돌려주는 것**. AI는 우리가 준 목록 중에서 고를 뿐이라, 오타를 낼 여지가 거의 없다.

**왜 `arguments`가 `{"product_id": "A100"}`인가**: `"product_id"`라는 키 이름은 **우리가 설명서에 정해준 것**이고, `"A100"`이라는 값은 **AI가 사용자 질문에서 찾아낸 것**.

`step.type`, `step.name`, `step.arguments`, `step.id` 같은 속성은 **`google-genai` SDK가 미리 만들어둔 것**. 우리가 정의한 게 아니라 꺼내 쓰기만 하면 된다.

### ④ 글자를 진짜 함수로 바꿔서 실행

AI가 준 건 `"get_product"`라는 **글자**다. **글자로는 함수를 부를 수 없다.**

```python
name = "get_product"
name("A100")          # 에러! name 은 그냥 글자
```

그래서 **글자 → 함수 변환표**가 필요하다.

```python
TOOL_FUNCTIONS = {
    "get_product": get_product,     # 키는 글자, 값은 함수 자체(괄호 없음)
}

func = TOOL_FUNCTIONS[step.name]        # 글자로 함수 찾기
result = func(**step.arguments)          # 찾은 함수 실행
```

`**step.arguments` → `{"product_id": "A100"}`를 풀어서 `func(product_id="A100")`처럼 넣어주는 것.

**안전장치**: `if step.name not in TOOL_FUNCTIONS:` 로 미리 검사하면, 등록해둔 함수만 실행되게 막을 수 있다. 딕셔너리는 정확히 일치하는 키만 찾으므로, 한 글자라도 다르면 그냥 실패한다(비슷한 걸 알아서 찾아주지 않는다).

### ⑤ 결과를 AI에게 돌려주기

함수 실행 결과는 딕셔너리라서 사용자에게 그대로 보여줄 수 없다. AI에게 다시 보내 문장으로 정리시킨다.

```python
function_result = {
    "type": "function_result",       # "함수 실행 결과다"라는 표시
    "name": function_call.name,       # 어떤 함수의 결과인지
    "call_id": function_call.id,      # "아까 네가 요청한 그 건에 대한 답이야" 번호표
    "result": [{"type": "text", "text": json.dumps(result, ensure_ascii=False)}],
}

final = client.interactions.create(
    model=model,
    input=[function_result],                    # 질문 대신 결과를 보냄
    tools=[get_product_tool],
    previous_interaction_id=interaction.id,     # 아까 그 대화 이어받기
    store=True,
)

print(final.output_text)    # "무선 키보드는 39,000원이고, 현재 재고는 12개 있습니다."
```

- **`json.dumps(딕셔너리)`** → 파이썬 딕셔너리를 글자로 바꿈. AI에게 보낼 땐 텍스트여야 하니까. `ensure_ascii=False`는 한글이 깨지지 않게 하는 옵션
- **`previous_interaction_id`** → 이게 없으면 AI는 아까 자기가 뭘 요청했는지 모른다. 갑자기 상품 정보만 툭 받으면 맥락을 못 찾는다.
- **`store=True`** → 서버에 저장해둬야 나중에 `previous_interaction_id`로 찾아올 수 있다.

**`create`를 두 번 부른다.** 처음엔 질문하려고, 두 번째는 결과를 알려주려고.

## 4. 이름이 일치해야 하는 곳 정리

세 곳에 `get_product`가 나오는데, 각각 이유가 다르다.

```python
def get_product(product_id):        # ①
    ...

get_product_tool = {
    "name": "get_product",          # ②
}

TOOL_FUNCTIONS = {
    "get_product": get_product,     # ③키        ③값
}
```

**따옴표가 있으면 그냥 글자, 없으면 그 함수 자체.**

| 관계 | 필수? | 이유 |
|---|---|---|
| ② = ③키 | **필수** | 둘 다 문자열. AI가 준 글자(②에서 온 것)로 딕셔너리(③키)를 찾으니 정확히 같아야 함. 우리가 손으로 맞춰 써야 하는 부분 |
| ③값 = ① | 같을 수밖에 없음 | "맞춰야 하는 규칙"이 아니라, **그 함수를 가리키는 유일한 방법**이 원래 지어진 이름을 쓰는 것이라서 |
| ③키 = ① | **필수 아님** | 실제로 `def 실제_함수_이름()` 으로 만들고 `{"get_product": 실제_함수_이름}` 로 등록해도 정상 동작함 (직접 테스트로 확인) |

지금 코드에서 셋이 다 똑같아 보이는 건 **우리가 헷갈리지 않으려고 일부러 통일한 것**이지, 파이썬이 강제하는 게 아니다. 실무에서도 통일해서 쓴다.

## 5. Function Calling 과 MCP 의 관계

**같은 게 아니다.**

- **Function Calling** = "AI가 함수 호출을 요청하고, 우리가 실행해서 돌려주는" 기본 메커니즘. 오늘 배운 것.
- **MCP (Model Context Protocol)** = 이 메커니즘을 **여러 프로그램이 공통으로 쓸 수 있게 표준화한 규격**.

지금 코드의 `TOOL_FUNCTIONS`나 검사 로직은 전부 이 스크립트 하나에 직접 짠 것이라 **다른 프로그램이 재사용할 수 없다.** MCP는 도구를 별도 서버로 만들어서 **어떤 AI 앱이든 표준 방식으로 가져다 쓸 수 있게** 하는 것.

> ➕ **더 알아두기**
> 8월 4일에 배운 "MCP는 USB-C 포트, Skill은 그 포트에 꽂는 장치" 비유와 연결하면, 오늘 배운 Function Calling은 그 USB-C 규격이 실제로 어떻게 동작하는지(요청→실행→결과 반환)를 코드 레벨에서 본 것이다.

## 오늘의 핵심 정리

1. **괄호 없으면 함수 자체, 괄호 있으면 실행 결과.** 딕셔너리에 함수를 저장해두는 것도 이 원리.
2. **대괄호는 꺼내기, 소괄호는 실행하기.** `TOOL_FUNCTIONS["이름"]("값")`
3. **스트리밍**: `stream=True`를 주면 완성본 대신 이벤트 흐름이 오고, `"step.delta"` 조각을 골라 실시간 출력.
4. **Function Calling**: AI는 "불러줘"라고 부탁만, 실행은 우리 코드가. `create`를 두 번 부른다(질문 → 결과 전달).
5. **AI가 주는 함수 이름은 글자**라서, `TOOL_FUNCTIONS` 같은 변환표로 진짜 함수를 찾아야 실행할 수 있다.

## ✅ 확인 질문
