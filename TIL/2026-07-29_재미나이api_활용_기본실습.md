  지금 만든게임은 완성된 게임으로 배포된것이라 정적웹사이트로써 제공된것임

  그래서 여러사람이 플레이해서 공유하거나 경쟁하는 실시간 온라인시스템을 만들수 없음.

  파이썬을 주로쓰기도하고 대부분의 데이터 전송을 제이슨으로 쓰는것치 추세이기 떄문.


## 2. API란?

  다른 회사가 만들어놓은 기능을 밖에서 쓸수 있도록 만들어논것을 api라고함.

  정확히는 기능 자체가 아니라 그 기능을 사용할수 있도록 지원하는것이 api


  ex) 저희는 이런 형테의 데이터를 이렇게 처리해서 드릴께요~ 하는것이 api임.


## 3. ai모델보다는 돈되는 시스템을 구상해라

  ai모델을 만들면 좋겠지만 그런 자원이 없기때문에 만드는것은 불가능.

  만들어진 ai모델을 제타같이. 그냥 활용해서 돈벌 방법을 구상하는것이 맞음.


  그래서 대부분 기업이 랭체인이나 n8n 처럼 ai에 그냥 슬쩍 끼워서 몸집을 불릴려고함.

  실제로 ai 모델이 없고 빌려서 유통회사처럼 그냥 파는것이 진실이지만..
