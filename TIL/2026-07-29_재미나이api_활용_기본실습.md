## 2. 정적 웹사이트와 서버-클라이언트 구조

> 11:00–12:00 정적 횝사이트와 동적횝사이트의 기본설명.

### 2.1 서버-클라이언트 구조의 설명

  지금 만든게임은 완성된 게임으로 배포된것이라 정적웹사이트로써 제공된것임

  그래서 HTML 에 소리는 mp3로 디자인츤 css등으로 이미 모든것들이 세팅되어있음.

  그래서 여러사람이 플레이해서 공유하거나 경쟁하는 실시간 온라인시스템을 만들수 없음.

  과거에 있던 cd로 프로그램을 배포하는것과 다른것이 없음.

  그래서 사용하는것이 서버-클라이언트 구조임.

### 2.2 서버를 만들때는 DB가 필요

  서버를 사용하는것은 데이터를 받아서 가공하여 제공하는것이 기본이기때문에 데이터베이스가 반드시 필요.

### 2.3 개발자의 종류

  개발자는 클라이언트를 개발하는 개발자를 프론트엔드,

  서버를 개발하는 개발자를 백엔드 개발자로 통칭.

  AI엔지니어는 굳이 따지자면 백엔드쪽에 좀더 가까움.

  그래서 데이터베이스를 반드시 알고있어야함.

  그래서 파이썬 배울꺼니깐 fast api배우면 좋을꺼같다고함.

### 2.4 과정중 배울것.

  1. ai 에이전트
  1. 서버
  1. DB
  1. 클라우드 활용

  이것들을 다 할줄 알아야함. 모르는건 카페가서 공부해서라도 알아서 배우지 않으면 안됨.

## 3. API와 기본 CS

> 13:00–14:00 기본적인 컴퓨터과학cs 내용 설명, API란

### 3.1 주로 JSON을 사용하게 될것

  파이썬을 주로쓰기도하고 대부분의 데이터 전송을 제이슨으로 쓰는것치 추세이기 떄문.

### 3.2 API란?

  다른 회사가 만들어놓은 기능을 밖에서 쓸수 있도록 만들어논것을 api라고함.

  정확히는 기능 자체가 아니라 그 기능을 사용할수 있도록 지원하는것이 api

  ex) 저희는 이런 형테의 데이터를 이렇게 처리해서 드릴께요~ 하는것이 api임.

### 3.3 ai모델보다는 돈되는 시스템을 구상해라

  ai모델을 만들면 좋겠지만 그런 자원이 없기때문에 만드는것은 불가능.

  만들어진 ai모델을 제타같이. 그냥 활용해서 돈벌 방법을 구상하는것이 맞음.

  그래서 대부분 기업이 랭체인이나 n8n 처럼 ai에 그냥 슬쩍 끼워서 몸집을 불릴려고함.

  실제로 ai 모델이 없고 빌려서 유통회사처럼 그냥 파는것이 진실이지만..

## 4. 재미나이 API 실습

> 14:00–18:00 실습

### 4.1 재미나이 API 사용하기.

  https://ai.google.dev/gemini-api/docs/get-started?hl=ko#python

  바탕화면에 포트폴리오 폴더 만들어서 이제 관리하기 시작할꺼임.

  클로드에게 깃허브에 포트폴리오라는 퍼블릭 레포지토리를 만들어서 폴더랑 연결해줘. 라고 요청해서

  포트폴리오라는 레포지토리가 나오면 그 문서 하나에 각각의 프로젝트가 연결되거나 보이도록 구성해야함. 그래서 HR담당자들이 귀찮아서라도 각각 안보기때문에 그렇게 보이게하면 됨.

### 4.2 git 레포지토리 파일중에 git ignore 사용법.

  해당 기능을 사용하면 이 파일에 올리고 싶지 않은 파일을 올려두면 업로드가 안됨.

  그래서 중요한 api 키같은거 보관하는 용도로 사용하게 되어있음.

### 4.3 실습 내용

  만원정도 들어있는 재미나이 유료 api를 가지고

  파이썬 파일 예제 하나 만들어서 입력한 한국어를 영어로 한줄 바꾸는 실습.

  그리고 사주 html 만들어서 해달라고 한 실습.

  동영상, 음성, 사진은 토큰을 많이먹어서 안하는게 좋다고함. 돈이 많이 안들어있다는듯.
