## 1. 파이썬 스코프(Scope)와 LEGB 규칙

### 1.1 실습 환경 — 파이썬 파일 실행하기

파이썬 파일을 실행할 때 **Ctrl+J**를 누르면 VSCode에서 터미널이 생긴다. 여기서 파이썬을 실행시키면 된다.

### 1.2 스코프(Scope)의 개념

스코프는 변수가 살아있는 범위, 즉 접근 가능한 유효 구역을 뜻한다. 변수 이름이 같더라도 작동하는 구역을 나누어 서로 간섭하지 않도록 관리하기 위해 필요하다.

- **지역 변수(Local Variable)**: 함수 내부에서 선언되어 해당 함수 내부에서만 접근 가능한 변수.
- **전역 변수(Global Variable)**: 함수 외부(파일 전체)에서 선언되어 어디서든 접근 가능한 변수.

`scope.py` 같은 파일명은 파이썬 고유의 기술이나 기능이 아니라, 스코프 개념을 실습하기 위해 임의로 지정한 파일 이름일 뿐이다. 파이썬에서는 파일 하나하나가 각각 하나의 모듈 역할을 하며, 파일 자체도 고유한 모듈 스코프(전역 스코프)를 가진다.

### 1.3 변수 탐색 우선순위: LEGB 규칙

파이썬이 코드 내에서 특정 변수를 찾을 때 훑어보는 우선순위 순서다. 가장 가까운 영역(L)부터 시작해 가장 넓은 영역(B)으로 찾아 올라가며, 먼저 발견된 변수를 사용한다.

1. **L (Local)**: 현재 작성·실행 중인 함수 내부 영역
2. **E (Enclosed)**: 현재 함수를 감싸고 있는 바깥 함수 내부 영역 (중첩 함수 구조일 때)
3. **G (Global)**: 파일 전체(모듈)에서 접근 가능한 영역
4. **B (Built-in)**: 파이썬이 기본으로 제공하는 내장 영역 (`print()`, `len()` 등)

### 1.4 함수 내부에서 바깥 변수 참조 및 수정 동작

- **읽기(Referencing)**: 전역 변수(Global)나 상위 함수의 변수(Enclosed)는 함수 내부에서 단순 조회 및 읽기가 가능하다.
- **재할당(`=` 연산자)**: 함수 내부에서 바깥 변수와 동일한 이름으로 `=`를 사용해 새 값을 할당하면, 바깥 변수의 값이 변경되는 것이 아니라 함수 내부에 전혀 다른 새로운 지역 변수가 생성된다. 바깥 전역 변수의 값 자체를 수정하려면 `global` 키워드를 명시해야 한다.
- **가변 객체(Mutable) 수정**: 리스트나 사전(Dict) 같은 가변 객체는 `=` 재할당이 아닌 요소 수정(`list[0] = value` 등)을 수행할 경우, 새 지역 변수를 생성하지 않고 기존 메모리 주소의 내부 데이터에 직접 접근하여 수정하므로 바깥의 실제 값도 함께 변경된다.

> ➕ **더 알아두기**
> 이 동작이 8월 13일에 배운 "참조와 복사"와 정확히 같은 원리다. 함수 인자로 리스트를 넘기는 것도 결국 `b = a`처럼 **같은 메모리 주소를 공유**하는 것이라서, 함수 안에서 요소를 수정(`list[0] = value`)하면 바깥까지 바뀐다. 반면 `=`로 통째로 재할당하면 그 지역 변수만 새 주소를 가리키게 되어 바깥에는 영향이 없다.

**⚠️ 헷갈리기 쉬운 점**

- **스코프의 오해**: 스코프 안에서 함수를 정의하는 것이 아니라, 모든 코드와 변수가 스코프라는 범주 규칙의 적용을 받는다. 함수가 정의되고 호출되는 순간 그 내부에 새로운 지역 스코프가 형성된다.
- **할당과 요소 수정의 차이**: 함수 내부에서 바깥 리스트 변수를 다룰 때, `a = [1, 2]`처럼 새로 할당하면 영향이 없지만 `a[0] = 99`처럼 내부 요소를 변경하면 바깥 데이터도 실제로 변경되므로 주의해야 한다.
- **Built-in 이름 덮어쓰기**: 함수 내부에서 `print = "hello"`와 같이 내장 함수 이름을 변수명으로 재정의하면 LEGB 규칙에 의해 내장 함수보다 지역 변수가 우선시되어 원래의 `print()` 기능을 사용할 수 없게 된다.

## 2. 파이썬 실습: 회문 판별 및 sorted 함수

### 2.1 문자열 슬라이싱을 활용한 회문(Palindrome) 판별

회문은 거꾸로 읽어도 동일한 문자열을 의미한다. 파이썬의 슬라이싱 기법(`[::-1]`)을 활용하면 별도의 반복문 없이 원본 문자열과 역순 문자열을 비교하여 간단히 판별할 수 있다.

```python
def is_palindrome(text):
    return text == text[::-1]


print(is_palindrome('수박이박수'))  # True
print(is_palindrome('abcde'))  # False
```

- `text[::-1]`: 문자열의 처음부터 끝까지 -1 간격(역순)으로 잘라내어 뒤집힌 문자열을 생성한다.
- `text == text[::-1]`: 원본 문자열과 뒤집힌 문자열이 같은지 비교하여 불리언(`True`/`False`) 값을 반환한다.

### 2.2 sorted() 함수를 이용한 데이터 정렬

- **데이터 타입 확인**: 숫자를 입력받더라도 `input()`의 기본 결과는 문자열(`str`)이며, 이를 `split()` 등으로 분할하여 `[1, 5, 3]` 형태의 시퀀스 데이터 구조로 가공했을 때 비로소 리스트가 된다.
- **`sorted()` 함수의 특징**: 리스트, 튜플, 문자열 등 순회 가능한 객체(Iterable)를 입력받아 **원본 데이터는 변경하지 않고**, 오름차순으로 정렬된 **새로운 리스트**를 생성하여 반환한다.

**⚠️ 헷갈리기 쉬운 점**

- **`sorted()`와 `.sort()`의 차이**: `sorted(data)`는 원본을 보존하며 정렬된 새 리스트를 반환하는 내장 함수이고, `data.sort()`는 리스트 객체 고유의 메서드로 원본 리스트 자체를 제자리(In-place)에서 수정하고 `None`을 반환한다.

## 3. 파이썬 정렬 알고리즘 (Sorting Algorithms)

### 3.1 정렬 알고리즘의 주요 종류와 동작 방식

- **선택 정렬 (Selection Sort)**: 전체 데이터 중 가장 작은 값을 찾아서(선택해서) 맨 앞으로 보내는 방식을 반복하는 정렬.
- **버블 정렬 (Bubble Sort)**: 인접한 두 원소를 비교하여 큰 값을 오른쪽으로 이동시키며, 거품이 위로 올라오듯 제일 큰 값부터 맨 뒤로 채워나가는 정렬.
- **퀵 정렬 (Quick Sort)**: 기준값인 피벗(Pivot)을 하나 정한 뒤, 피벗보다 작은 값은 왼쪽, 큰 값은 오른쪽으로 나눈 후(분할 정복) 재귀적으로 정렬하는 빠르고 효율적인 정렬.
- **카운팅 정렬 (Counting Sort, 계수 정렬)**: 원소 간의 대소 비교를 하지 않고, 딕셔너리나 배열을 활용해 **각 숫자가 몇 번 나왔는지 개수(Count)를 세어** 최솟값부터 개수만큼 순서대로 배치하는 정렬.

**⚠️ 헷갈리기 쉬운 점**

- **비교 정렬 vs 계수 정렬**: 버블·선택·퀵 정렬은 원소 간 비교를 기반으로 하지만, 카운팅 정렬은 값의 개수를 세는 방식이다. 카운팅 정렬은 정수 범위가 제한적이고 중복 데이터가 많을 때 매우 빠르다.

## 4. 2차원 리스트 탐색 및 델타 이동 (Delta Search)

### 4.1 핵심 개념 및 동작 원리

- **2차원 리스트 탐색**: 행(row, `i`)과 열(column, `j`)이라는 2개 축으로 구성된 격자형 구조에서 요소에 접근하기 위해 이중 `for`문을 사용한다.
- **델타 이동 (Delta Search)**: 격자판의 특정 위치 `(i, j)`를 기준으로 상·하·좌·우 인접 칸을 탐색할 때 사용한다. 2차원 공간이므로 행과 열의 변화량을 나타내는 2개의 변수(또는 2개 축의 데이터)가 반드시 독립적으로 필요하다.

### 4.2 델타 구현 방식 비교

**1. `di`, `dj` 1차원 리스트 분리 방식 (기초/표준)**

행 변화량 리스트(`di`)와 열 변화량 리스트(`dj`)를 따로 두고 인덱스 `d`로 접근하는 방식이다. 행과 열의 역할이 명확히 구분되어 직관적이다.

```python
di = [0, 0, 1, -1]  # 우, 좌, 하, 상 (행 변화)
dj = [1, -1, 0, 0]  # 우, 좌, 하, 상 (열 변화)

for d in range(4):
    ni = i + di[d]
    nj = j + dj[d]
```

**2. 튜플 묶음 & 언패킹 방식 (응용)**

방향별 변화량을 `(di, dj)` 튜플 세트로 묶어 하나의 리스트로 관리하는 방식이다. `for`문에서 언패킹(Unpacking)을 이용해 인덱스 접근(`[d]`) 없이 바로 값을 추출한다.

```python
delta = [(0, 1), (0, -1), (1, 0), (-1, 0)]  # (행 변화, 열 변화)

for di, dj in delta:
    ni = i + di
    nj = j + dj
```

### 4.3 실무 & 코딩 테스트 필수 체크 포인트

- **경계 조건(Boundary Check)**: 탐색 시 격자 범위를 벗어나는 `IndexError`를 방지하기 위해 조건문(`0 <= ni < N and 0 <= nj < M`)을 반드시 작성해야 한다.
- **하드코딩 지양**: `mat[i+1][j]`, `mat[i-1][j]`처럼 4방향을 직접 일일이 쓰는 것보다 델타 배열과 반복문을 활용해야 코드의 가독성과 확장성이 좋아진다.
