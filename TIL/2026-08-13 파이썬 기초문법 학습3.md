## 1. 컨테이너 자료형 기초 (리스트, 시퀀스, 가변성, 인덱싱/슬라이싱)

### 1.1 리스트(List)의 개념과 특징

여러 개의 데이터를 순서대로 하나로 묶어서 관리하는 자료형이다. 대괄호(`[]`)로 감싸서 생성하며, 내부에 숫자, 문자열, 다른 리스트 등 다양한 형태의 데이터를 담을 수 있다.

- 데이터의 순서(인덱스)가 유지된다.
- 데이터의 추가, 수정, 삭제가 자유롭다.
- 실무에서는 데이터베이스에서 조회한 여러 개의 사용자 정보나, 쇼핑몰의 상품 목록처럼 동일한 성격의 데이터 여러 개를 다룰 때 활용한다.

### 1.2 순서가 있는 자료형과 없는 자료형

파이썬 자료형은 순서의 유무에 따라 시퀀스(Sequence)와 비시퀀스(Non-sequence) 유형으로 구분된다.

- **순서가 있는 자료형 (시퀀스)**: 리스트(`list`), 튜플(`tuple`), 문자열(`str`) — 위치 정보인 인덱스(`[0]`)를 통해 특정 위치의 데이터에 접근 가능하다.
- **순서가 없는 자료형 (비시퀀스)**: 세트(`set`), 딕셔너리(`dict`) — 순서 개념이 없어서 인덱스를 통한 접근이 불가능하거나 키(Key)를 통해 접근해야 한다.
- **추가 개념 (튜플과 세트)**:
  - 튜플(`tuple`): 리스트처럼 순서가 있지만 수정이 불가능하다.
  - 세트(`set`): 순서가 없고 중복을 허용하지 않는다.
- 실무에서는 순서 유지 및 중복 제거(세트) 또는 데이터 변경 방지(튜플) 등 목적에 맞춰 적절한 데이터 구조를 선택한다.

### 1.3 변경 가능성 (가변성: Mutable vs Immutable)

파이썬 데이터는 생성 후 변경 가능 여부에 따라 가변(Mutable)과 불변(Immutable) 객체로 구분된다.

- **가변(Mutable)**: 생성된 후에도 내부 값을 수정할 수 있다. (예: `list`, `dict`, `set`)
- **불변(Immutable)**: 생성된 후 내부 값을 수정할 수 없다. (예: `int`, `str`, `tuple`)
- **중요성**: 메모리 동작 방식과 함수 데이터 전달 방식에 영향을 준다. 가변 객체를 함수 내부에서 수정하면 원본 데이터도 변경되지만, 불변 객체는 수정 시 새로운 객체가 생성된다.
- 실무에서는 멀티태스킹 환경에서 값 변경으로 인한 오류를 방지하거나, 중요 설정값을 보호할 때 불변 데이터 구조를 활용한다.

### 1.4 인덱싱 (Indexing)

순서가 있는 자료형(리스트, 문자열, 튜플)에서 위치 번호(인덱스)를 지정하여 특정 위치의 데이터에 직접 접근하는 방법이다.

- **양수 인덱스**: `0`부터 시작하여 앞에서부터 순서대로 위치를 지정한다.
- **음수 인덱스**: `-1`부터 시작하여 뒤에서부터 거꾸로 위치를 지정한다. (예: `-1`은 맨 마지막 요소)
- 실무에서는 리스트의 첫 번째 항목(`items[0]`)을 추출하거나 파일 확장자 확인 시 맨 뒤 항목(`filename[-3:]`)을 추출할 때 사용된다.

### 1.5 슬라이싱 (Slicing)

인덱스를 활용하여 자료형의 특정 범위를 연속으로 잘라내는 기술이다. `[시작:끝:증감폭]` 형태로 작성한다.

- **끝 인덱스 미포함**: 지정한 끝 인덱스의 바로 앞 요소까지만 추출된다. (미만 개념)
- **생략 표현**:
  - `[:3]`: 시작 인덱스를 생략하면 처음부터 자른다.
  - `[2:]`: 끝 인덱스를 생략하면 끝까지 자른다.
  - `[::-1]`: 증감폭에 `-1`을 지정하면 전체 리스트나 문자열을 역순으로 뒤집는다.
- 실무에서는 긴 데이터 목록을 일정 크기로 잘라서 보여주는 페이지네이션(Pagination) 기능 구현이나 파일 경로에서 파일명/확장자를 추출할 때 활용된다.

**⚠️ 헷갈리기 쉬운 점**

- 슬라이싱의 `끝` 인덱스 숫자는 결과에 포함되지 않으므로(미만 조건), 추출하고 싶은 범위보다 1 큰 숫자를 입력해야 한다.
- 가변 객체(`list`)를 다른 변수에 할당하거나 함수 파라미터로 넘길 때는 원본 데이터까지 수정될 수 있으므로 불변 객체(`tuple`)와의 차이를 유의해야 한다.

## 2. 컨테이너 자료형 활용 (멤버십 연산자, 리스트 순회, 주요 메서드)

### 2.1 멤버십 연산자 (Membership Operator)

특정 데이터가 컨테이너(리스트, 튜플, 문자열, 딕셔너리 등) 내에 존재하는지 여부를 확인하는 연산자다.

- **종류**: `in`, `not in`
- **반환 값**: Boolean 타입 (`True` 또는 `False`)
- **특징**:
  - 조건문(`if`)과 결합하여 조건 분기 처리에 주로 활용된다.
  - 딕셔너리에서 멤버십 연산자를 사용할 때는 '값(Value)'이 아닌 '키(Key)'를 기준으로 존재 여부를 검사한다.
  - 리스트에서의 `in` 검사는 순차 탐색이므로 데이터량에 따라 시간이 걸릴 수 있지만, 세트(`set`)나 딕셔너리(`dict`)에서의 `in` 검사는 매우 빠르게 처리된다.

```python
fruits = ["apple", "banana", "orange"]

print("apple" in fruits)      # True
print("grape" not in fruits)  # True
```

**실무 활용**: 권한 검사(관리자 목록 포함 여부), 중복 가입 방지, 금지어 필터링 등 데이터 존재 유무 확인 로직에 사용된다.

### 2.2 리스트 순회 (반복문 활용)

리스트의 요소들을 순회하는 방법은 목적에 따라 3가지 패턴으로 나뉜다.

**1. 직접 순회 (`for item in list`)**: 인덱스 없이 요소의 값만 필요할 때 사용한다. 코드가 간결하고 가독성이 가장 뛰어나다.

**2. `range(len(list))` 활용**: 인덱스 번호를 기반으로 순회하며 요소의 위치 정보가 필요하거나, 인덱스를 통해 리스트 내부 값을 직접 수정해야 할 때 사용한다. 여러 리스트의 동일한 인덱스를 동시에 참조할 때 유용하다.

```python
fruits = ["apple", "banana", "cherry"]

for i in range(len(fruits)):
    print(f"{i}번째 과일: {fruits[i]}")
```

**3. `enumerate()` 함수 활용**: 인덱스와 값을 동시에 안전하게 가져오고자 할 때 사용한다. 실무에서는 `range(len())` 구조보다 `enumerate()`를 사용하는 것이 가독성과 안전성 측면에서 권장된다.

```python
fruits = ["apple", "banana"]

for idx, fruit in enumerate(fruits):
    print(idx, fruit)  # 0 apple, 1 banana
```

### 2.3 리스트의 삽입, 삭제, 복제 메서드

리스트는 가변(Mutable) 객체이므로 내부 요소를 조작할 수 있는 다양한 전용 메서드를 제공한다.

**삽입 (Insertion)**

- `append(val)`: 리스트 맨 뒤에 단일 요소를 추가한다.
- `insert(index, val)`: 지정한 인덱스 위치에 요소를 삽입한다.
- `extend(iterable)`: 다른 리스트나 반복 가능한 객체를 연결하여 확장한다.

**삭제 (Deletion)**

- `remove(val)`: 지정한 값을 가진 첫 번째 요소를 찾아 삭제한다.
- `pop(index)`: 지정한 인덱스의 요소를 삭제하면서 해당 값을 반환한다. (인덱스 생략 시 맨 뒤 요소 추출 및 삭제)
- `clear()`: 리스트 내의 모든 요소를 제거하여 빈 리스트로 만든다.

**복제 (Copying)**

- 단순 할당 연산자(`=`) 사용 시 메모리 주소가 공유되므로 한쪽을 수정하면 원본 데이터도 함께 변경된다.
- 독립된 새로운 리스트로 객체를 복제하려면 `.copy()` 메서드나 슬라이싱(`[:]`) 표현식을 사용해야 한다.

**실무 활용**: 장바구니 상품 추가(`append`), 결제 완료/선택 항목 제거(`pop`/`remove`), 원본 데이터를 유지한 상태로 가공하기 위한 데이터 복사(`.copy()`) 등에 자주 사용된다.

**⚠️ 헷갈리기 쉬운 점**

- 리스트 변수를 `list_b = list_a` 형태로 단순히 대입하면 두 변수가 동일한 리스트 메모리를 참조하므로, 복사본을 만들고자 할 때는 반드시 `list_b = list_a.copy()` 또는 `list_b = list_a[:]`를 사용해야 한다.
- 딕셔너리에서 `in` 연산자를 사용할 때 값을 기준으로 찾으려면 `dict.values()`를 명시적으로 지정해야 하며, 기본 `in` 연산은 Key에 대해서만 동작한다.

## 3. 참조와 복사: 얕은 복사 vs 깊은 복사

### 3.1 기본 동작: `b = a` (참조 연결)

- **공통점**: 실행하는 순간 `a`와 `b`는 **같은 메모리 주소**를 바라본다.
- **차이점 (타입에 따라 다름)**:
  - **불변 객체 (숫자, 문자열 등)**: `a = 10`처럼 수정하면 `a`에 **새 주소가 할당**되어 `b`에 영향을 주지 않는다.
  - **가변 객체 (리스트, 딕셔너리 등)**: `a.append()`처럼 내부를 수정하면 같은 주소를 공유하는 **`b`도 함께 변경**된다.

### 3.2 리스트 재할당 vs 내부에 값 덮어쓰기

| 구문 | 메모리 주소 (id) | b = a 관계 |
|---|---|---|
| `a = [10, 20]` | 새 주소 할당 (주소 끊김) | `b`는 이전 값 유지 (동기화 끊김) |
| `a[:] = [10, 20]` | 기존 주소 유지 | `b`도 함께 `[10, 20]`으로 변경됨 |

### 3.3 리스트 독립 백업 만드는 법: `copy()`

`a`를 계속 업데이트하되, `b`에 **초기·이전 상태를 백업**으로 보존하고 싶다면 `b = a`가 아닌 **복사 명령**을 써야 한다.

**대표 방법**: `b = a.copy()` (또는 `b = a[:]`)

**결과**: 내용물은 같지만 메모리 주소가 완전히 달라지므로, `a`를 수정해도 `b`는 안전하게 유지된다.

### 3.4 슬라이싱을 이용한 데이터 복사

단순 대입 연산자(`a = b`)는 리스트의 메모리 주소(참조)를 공유하므로 한쪽을 수정하면 다른 쪽도 함께 변경된다. 하지만 슬라이싱 표현식(`a = b[:]` 또는 `a = b[0:len(b)]`)을 사용하면 새로운 메모리 공간에 동일한 요소들을 가진 별개의 리스트 객체가 생성되므로 원본과 독립된 복사본을 만들 수 있다.

```python
b = [1, 2, 3]
a = b[:]  # 슬라이싱을 이용한 독립 리스트 생성

a[0] = 99
print(b)  # [1, 2, 3] (원본 데이터 유지)
```

### 3.5 얕은 복사 (Shallow Copy) vs 깊은 복사 (Deep Copy)

1차원 리스트가 아닌 '리스트 내부에 또 다른 리스트가 존재하는 중첩 구조(2차원 이상의 데이터)'에서는 복사 방식에 따라 내부 데이터의 독립 여부가 달라진다.

- **얕은 복사 (Shallow Copy)**
  - `리스트명.copy()` 메서드나 슬라이싱(`b[:]`) 방식이 여기에 해당한다.
  - 가장 겉면의 껍데기 리스트만 새 메모리에 생성하고, 내부 중첩된 리스트나 객체는 기존의 메모리 주소를 그대로 공유한다.
  - 따라서 1차원 데이터 복사에는 문제가 없으나, 중첩된 내부 리스트의 값을 변경할 경우 원본 데이터에도 영향을 미친다.
- **깊은 복사 (Deep Copy)**
  - 파이썬 내장 모듈인 `copy`를 불러와 `copy.deepcopy(리스트명)` 형태로 사용한다.
  - 아무리 복잡하게 중첩된 데이터 구조라도 내부의 모든 객체까지 통째로 새로운 메모리에 재귀적으로 복제하여 완벽히 독립된 개체로 만든다.

```python
import copy

b = [[1, 2], [3, 4]]
a = copy.deepcopy(b)  # 깊은 복사 수행

a[0][0] = 99
print(b)  # [[1, 2], [3, 4]] (원본 데이터 완벽 보호)
```

**실무 활용**

- 간단한 1차원 데이터 목록은 가독성을 위해 `b.copy()`나 `b[:]`를 자주 활용한다.
- 데이터베이스에서 가져온 복잡한 JSON 구조, API 응답 데이터, 2차원 배열 데이터처럼 원본 훼손이 절대 없어야 하는 분석·가공 작업에서는 `copy.deepcopy()`를 필수적으로 사용한다.

### 3.6 두 변수 값 교환: `a, b = b, a`

파이썬에서 임시 변수(`temp`) 없이 두 값을 서로 맞바꾸는 구문이다.

**원리**: 우변 `(b, a)`를 튜플로 한 번에 묶어(패킹) 동시에 평가한 뒤, 좌변 `a, b`에 각각 풀어서(언패킹) 할당하기 때문에 안전하게 값이 교환된다.

리스트 요소 순서 교환(`arr[0], arr[1] = arr[1], arr[0]`)에도 동일하게 활용할 수 있다.

**⚠️ 헷갈리기 쉬운 점**

- `리스트명.copy()`와 `b[:]`는 **동일한 얕은 복사**다. `리스트명.copy()`를 사용했다고 해서 중첩된 내부 리스트까지 깊은 복사가 되는 것은 절대 아니므로 주의해야 한다.
- 중첩 리스트 구조에서 얕은 복사를 수행한 후 내부 항목을 수정하면, 원본 리스트의 내부 항목도 함께 변경되어 예측하지 못한 버그가 발생할 수 있다.

## 4. 문자열 다루기: 순회·포맷팅·메서드·불변성

### 4.1 문자열 순회 패턴 비교

문자열(`str`)은 순서가 있는 시퀀스(Sequence) 자료형이므로 목적과 상황에 맞게 3가지 순회 방식을 활용한다.

**1. 직접 순회 (`for char in sentence`)**: 인덱스가 필요 없이 단순 글자 탐색만 진행할 때 사용한다. 가독성이 가장 뛰어나고 깔끔한 파이썬 표준 스타일 방식이다.

**2. 인덱스 기반 순회 (`for i in range(len(sentence))`)**: 각 문자의 위치(인덱스 번호) 정보가 직접적으로 필요할 때 활용한다. `sentence[i]` 형태로 특정 위치 데이터를 인덱싱한다.

**3. `enumerate()` 활용 순회 (`for i, char in enumerate(sentence)`)**: **인덱스와 문자가 동시에 필요할 때 가장 권장되는 방식**이다. `enumerate()`는 순서가 있는 시퀀스 객체를 입력받아 **(인덱스, 요소)** 형태의 튜플로 한 글자·한 항목씩 반환한다. 별도의 인덱싱 조회가 필요 없어 가독성과 코드 안전성이 우수하다.

```python
sentence = "hello"

for i, char in enumerate(sentence):
    print(f"index: {i}, char: {char}")
```

**실무 활용**: 특정 문자가 처음 나타나는 위치 탐색, 문자열 가공 시 인덱스별 조건 처리, 로그 데이터 출력 등에 자주 사용된다.

### 4.2 문자열 포맷팅 (String Formatting)

문자열 내에 변수나 연산 결과를 삽입하는 대표적인 4가지 방식이다.

1. **`f-string` (`f"hello {name}"`) [강력 권장]**: 따옴표 앞에 `f`를 붙이고 중괄호 `{}` 안에 변수나 식을 직접 작성한다. 가독성이 뛰어나고 실행 속도가 가장 빠르며 현대 파이썬 표준 방식이다.
2. **`.format()` 메서드 (`"hello {}".format(name)`)**: 문자열 뒤에 `.format()`을 호출하여 중괄호 위치에 값을 순서대로 대입한다.
3. **더하기 연산자 `+` (`"hello " + name`)**: 문자열 간 단순 연결에 사용되나, 숫자형 변수는 `str()`로 타입 변환 후 연결해야 한다.
4. **`%` 포맷팅 (`"hello %s" % name`)**: C언어 스타일의 초창기 방식이며 레거시 코드에서 간혹 확인된다.

```python
name = "Python"
age = 30

# f-string 사용 예시
print(f"이름: {name}, 나이: {age}")
```

### 4.3 핵심 문자열 메서드

| 메서드 | 역할 및 특징 | 사용 예시 | 반환 결과 |
|---|---|---|---|
| `.split(sep)` | 구분자 기준(생략 시 공백)으로 쪼개어 **리스트 반환** | `"a,b,c".split(",")` | `['a', 'b', 'c']` |
| `"sep".join(seq)` | 리스트/튜플의 문자열들을 구분자로 연결해 **문자열 반환** | `"-".join(['010', '1234'])` | `"010-1234"` |
| `.strip()` | 문자열 양쪽 끝의 공백 및 줄바꿈(`\n`) 제거 | `" hello \n".strip()` | `"hello"` |
| `.replace(old, new)` | 특정 문자열을 지정한 다른 문자열로 교체 | `"hello world".replace("world", "python")` | `"hello python"` |
| `.find(sub)` | 찾으려는 문자열의 시작 **인덱스 반환** (없을 시 `-1`) | `"hello".find("e")` | `1` |
| `.index(sub)` | 찾으려는 문자열의 시작 **인덱스 반환** (없을 시 `ValueError`) | `"hello".index("e")` | `1` |
| `.startswith(prefix)` | 특정 문자(열)로 시작하는지 검사 (Boolean 반환) | `"hello".startswith("he")` | `True` |
| `.endswith(suffix)` | 특정 문자(열)로 끝나는지 검사 (Boolean 반환) | `"hello".endswith("o")` | `True` |
| `.upper()` / `.lower()` | 대문자 / 소문자로 전체 변환 | `"Hi".lower()` | `"hi"` |

```python
# split과 join 예시
text = "python,java,javascript"
languages = text.split(",")        # ['python', 'java', 'javascript']
result = " - ".join(languages)      # "python - java - javascript"
```

### 4.4 문자열 메서드 사용 시 핵심 주의사항 (불변성)

문자열은 **불변(Immutable)** 객체이므로, `.replace()`, `.strip()`, `.upper()` 등의 메서드를 호출하더라도 **원본 문자열은 절대 변경되지 않는다.**

```python
text = "hello"
text.replace("h", "H")
print(text)  # "hello" (원본은 절대 안 바뀜!)

# 변경된 값을 반영하려면 변수에 다시 할당해야 함
text = text.replace("h", "H")
print(text)  # "Hello"
```

### 4.5 가변(Mutable) vs 불변(Immutable) 동작 비교

- **리스트 (Mutable - 가변)**: `.append()`, `.sort()`, `.reverse()` 등 주요 메서드가 **원본 데이터 자체를 직접 변경**한다. (In-place operation, 반환값은 `None`)
- **문자열 (Immutable - 불변)**: `.replace()`, `.upper()`, `.strip()` 등 모든 가공 메서드가 **원본을 변경하지 않고 새로운 문자열 객체를 생성하여 반환**한다. 원본 데이터를 수정하려면 가공된 반환값을 변수에 **재할당**해야 한다.

**⚠️ 헷갈리기 쉬운 점**

- `enumerate()`는 인덱스와 값을 `(index, value)` 형태의 튜플로 반환하므로, `for i, char in enumerate(sentence):`처럼 변수 2개로 바인딩하여 수신해야 한다.
- 문자열의 메서드를 호출만 하고 재할당하지 않으면(`text.replace(...)`), 원본 문자열 `text`는 아무런 변화 없이 유지되므로 가공 결과가 누락되는 실수를 주의해야 한다.
- **`.find()` vs `.index()`의 예외 처리 차이**: `.find()`는 찾는 문자가 없으면 `-1`을 반환하므로 조건 분기 처리에 안전하다. `.index()`는 찾는 문자가 없으면 프로그램이 에러(`ValueError`)를 내며 중단되므로 예외 처리가 필요하다.
- **리스트 메서드 vs 문자열 메서드 동작 차이**: 리스트의 `.append()`, `.sort()` 등은 원본을 직접 수정하는 In-place 동작(가변성)을 한다(반환값: `None`). 문자열의 `.replace()`, `.upper()` 등은 원본을 건드리지 않고 새로운 문자열을 생성하여 반환(불변성)하므로 반환값을 새 변수에 받아야만 한다.

## 5. 세트(Set) 자료형과 메서드 활용

### 5.1 세트(Set)의 핵심 특징

1. **중복 불가 (Uniqueness)**: 동일한 값이 입력되면 자동으로 중복이 제거되어 단 하나만 남는다.
2. **순서 없음 (Unordered)**: 요소들의 순서가 유지되지 않는다.
3. **인덱싱 불가 (No Indexing)**: 순서가 없으므로 `s[0]`처럼 인덱스 번호로 특정 위치에 접근할 수 없으며, 접근 시 `TypeError`가 발생한다.

```python
s = {1, 2, 2, 3}
print(s)  # {1, 2, 3} (중복 자동 제거)
```

### 5.2 세트의 순회 (Iteration)

인덱스가 없어 위치 기반 접근은 불가능하지만, 시퀀스 객체처럼 `for`문 순회 및 멤버십 연산은 동일하게 지원한다.

- **직접 순회 (`for item in s`)**: 순서는 보장되지 않지만 안의 요소들을 하나씩 순회할 수 있다.
- **`enumerate()` 순회**: 인덱스가 없더라도 `enumerate()`를 사용하면 0부터 시작하는 가상의 순번을 할당하여 순회할 수 있다.

```python
s = {"apple", "banana", "cherry"}

# 직접 순회
for fruit in s:
    print(fruit)

# enumerate 순회 (임의의 순번 부여)
for idx, fruit in enumerate(s):
    print(idx, fruit)
```

### 5.3 세트의 추가 및 삭제 메서드

| 구분 | 메서드 | 역할 및 특징 | 사용 예시 |
|---|---|---|---|
| 추가 | `.add(element)` | 단일 요소를 1개 추가 | `s.add(4)` |
| | `.update(iterable)` | 리스트, 튜플 등 여러 요소가 담긴 묶음을 한 번에 추가 | `s.update([4, 5, 6])` |
| 삭제 | `.remove(element)` | 지정한 요소를 삭제 (지우려는 값이 없으면 **`KeyError` 발생**) | `s.remove(2)` |
| | `.discard(element)` | 지정한 요소를 삭제 (지우려는 값이 없어도 **에러 없이 안전하게 통과**) | `s.discard(99)` |
| | `.pop()` | 임의의 요소 하나를 꺼내며 삭제 | `item = s.pop()` |
| | `.clear()` | 세트 내의 모든 요소를 삭제하여 빈 세트로 만듦 | `s.clear()` |

**⚠️ 헷갈리기 쉬운 점**

- **`.add()` vs `.update()` 차이**: `.add([1, 2])`처럼 리스트를 `.add()`에 전달하려 하면 리스트 자체가 불변 객체가 아니므로 에러(`TypeError: unhashable type: 'list'`)가 발생한다. 여러 요소를 한 번에 풀어서 넣을 때는 반드시 `.update()`를 사용해야 한다.
- **`.remove()` vs `.discard()` 선택**: 안전한 코드 작성을 위해서는 삭제 대상 데이터의 존재 유무가 불확실할 때 예외를 발생시키지 않는 `.discard()`를 사용하는 것이 권장된다.
- **빈 세트 생성 문법**: 빈 세트를 만들 때는 `{}`를 사용하면 빈 딕셔너리(`dict`)가 생성되므로 반드시 `s = set()` 함수를 사용해야 한다.

## 6. 튜플 및 딕셔너리 자료형 정리

### 6.1 튜플(Tuple) 자료형의 특징 및 활용

1. **불변성 (Immutable)**: 한 번 생성되면 요소를 추가, 삭제, 수정할 수 없다. (`list`와의 핵심 차이점)
2. **소괄호 생략 가능**: `t = 1, 2, 3`과 같이 괄호 없이 콤마만으로 정의할 수 있다.
3. **언패킹(Unpacking) 및 값 교환**: `x, y = (10, 20)` 구조로 다중 변수 대입이 가능하며, `a, b = b, a` 방식의 값 교환 시 내부적으로 튜플을 활용한다.
4. **함수 다중 반환값**: `return a, b` 형태는 내부적으로 두 값을 1개의 튜플로 묶어 반환한다.
5. **불변 객체로의 활용**: 값이 변하지 않으므로 딕셔너리의 Key나 세트(Set)의 요소로 사용할 수 있다.

### 6.2 딕셔너리(Dictionary) 자료형의 핵심 구조

콜론(`:`)을 기준으로 **왼쪽이 Key, 오른쪽이 Value**로 구성된 `{Key: Value}` 형태의 자료형이다.

1. **Key와 Value의 제약 조건**:
   - **Key**: 중복 불가능. 해시(Hash) 계산이 가능한 **불변(Immutable) 데이터만 사용 가능**하다. (정수, 실수, 문자열, 불리언, 튜플 가능 / 리스트, 딕셔너리, 세트 불가능)
   - **Value**: 중복 가능. 문자열, 숫자, 리스트, 딕셔너리, 함수 등 **모든 자료형을 제약 없이 사용 가능**하다.
2. **Key 중복 시 동작 방식**: 중복된 Key를 작성하면 에러가 발생하지 않고 **가장 마지막에 작성된 Value로 덮어씌워진다.** 예: `students = {"kyle": 10, "kyle": 20}` → `{"kyle": 20}`

### 6.3 `dict()` 함수 및 `zip()`을 통한 형변환

Key-Value 쌍으로 매핑 가능한 2차원 구조 데이터를 딕셔너리로 변환할 수 있다.

- **튜플/리스트 쌍 형변환**: `dict([("a", 1), ("b", 2)])` → `{'a': 1, 'b': 2}`
- **`zip()` 함수 결합**: 두 시퀀스를 묶을 때 **첫 번째(왼쪽) 인자가 Key, 두 번째(오른쪽) 인자가 Value**가 된다.

```python
keys = ["kyle", "alex"]
scores = [10, 20]

# 왼쪽(keys) -> Key, 오른쪽(scores) -> Value
student_dict = dict(zip(keys, scores))  # {'kyle': 10, 'alex': 20}
```

### 6.4 중괄호 `{}` 초기화 시 딕셔너리와 세트 구분 기준

| 작성 형태 | 데이터 구조 | 판별 결과 |
|---|---|---|
| `{Key: Value}` | 콜론(`:`) 존재 | `dict` (딕셔너리) |
| `{Value1, Value2}` | 콜론(`:`) 없이 콤마 구분 | `set` (세트) |
| `{}` | 내용이 비어 있음 | `dict` (딕셔너리) |

> ⚠️ **주의**: 비어있는 세트를 선언할 때는 반드시 `set()` 함수를 사용해야 한다. (`s = {}`는 빈 딕셔너리로 생성됨)

### 6.5 Value로 Key를 탐색하는 방법

딕셔너리는 Key → Value 탐색만 지원하므로, Value로 Key를 찾으려면 별도의 로직이 필요하다.

- **단일 탐색 (`for`문)**: `.items()`를 순회하며 조건에 맞는 첫 Key 탐색 후 `break`
- **다중 탐색 (컴프리헨션)**: `[k for k, v in dict.items() if v == target]`
- **역딕셔너리 구성**: `{v: k for k, v in dict.items()}`로 Key와 Value의 위치를 뒤집어 새로운 딕셔너리 생성

## 7. 딕셔너리(Dictionary) 조회·삭제·멤버십 연산 정리

### 7.1 데이터 조회 (Access)

딕셔너리에서 Key를 통해 Value에 접근할 때는 접근 방식에 따른 예외 처리 특성을 명확히 구분해야 한다.

| 방식 | 특징 및 에러 처리 | 사용 예시 |
|---|---|---|
| `dict[key]` | Key가 존재하지 않을 시 **`KeyError` 발생하며 프로그램 중단** | `student["kyle"]` |
| `.get(key)` | Key가 존재하지 않을 시 **`None` 반환** (안전한 접근 가능) | `student.get("alex")` |
| `.get(key, default)` | Key가 없을 시 `None` 대신 지정한 **기본값(default) 반환** | `student.get("alex", 0)` |

```python
student = {"kyle": 20}

# 안전한 조회 방식
age = student.get("alex", 0)  # alex가 없으므로 0 반환
```

### 7.2 데이터 삭제 (Delete)

| 메서드 / 키워드 | 역할 및 반환 특징 | 사용 예시 |
|---|---|---|
| `del dict[key]` | 지정한 Key-Value 쌍을 바로 삭제 (없는 Key 삭제 시 `KeyError`) | `del student["kyle"]` |
| `.pop(key)` | 지정한 Key-Value 쌍을 삭제하면서 **해당 Value를 반환** | `val = student.pop("kyle")` |
| `.pop(key, default)` | 없는 Key여도 에러 대신 지정한 기본값을 반환하며 안전하게 처리 | `val = student.pop("alex", 0)` |
| `.clear()` | 딕셔너리 내 모든 요소를 제거하여 **빈 딕셔너리(`{}`)** 생성 | `student.clear()` |

### 7.3 멤버십 연산자 (`in` / `not in`)

딕셔너리에 특정 데이터가 존재하는지 검사할 때 사용하며, **기본 대상은 항상 Key**다.

- **Key 존재 확인**: `"key" in dict` — 딕셔너리 내부 해시 테이블을 직접 조회하므로 데이터 크기와 상관없이 **속도가 매우 빠르다 (O(1))**.
- **Value 존재 확인**: `val in dict.values()` — `.values()` 메서드를 통해 Value 목록 전체를 순회하며 확인해야 한다.

```python
student = {"kyle": 20, "alex": 30}

# Key 존재 검사
print("kyle" in student)        # True
print("john" in student)        # False

# Value 존재 검사
print(20 in student.values())   # True
```

**⚠️ 핵심 요약 및 실무 패턴**

- **예외 방지 조회 패턴**: 키 존재 유무가 불확실할 때는 `dict[key]` 대신 `.get()`을 사용하거나, `if key in dict:` 조건문으로 존재 여부를 먼저 검증하는 패턴이 표준적으로 사용된다.
- **멤버십 검사의 성능**: 리스트에서의 `in` 연산은 순차 탐색(O(N))인 반면, 딕셔너리 Key에서의 `in` 연산은 해시 기반 탐색(O(1))이므로 대용량 데이터 조회 시 딕셔너리가 훨씬 유리하다.
