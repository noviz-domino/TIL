### 머신러닝은 무엇인가

머신러닝은 데이터로부터 패턴이나 행동 전략을 학습해 예측·분석·판단·생성 등의 작업을 수행하는 기술이다.
여기서 모델은 입력을 받아 예측 등의 결과를 내는 계산 구조를 말한다.

예를 들어 스팸 메일을 구분하는 규칙을 직접 만든다면 “제목에 무료라는 단어가 있으면 스팸”이라고 정할 수 있다.
하지만 정상 메일에도 그 단어가 들어갈 수 있고, 스팸 메일은 다른 표현을 사용할 수 있다.

모델은 여러 입력 정보와 정답 사이의 관계를 학습하고, 처음 보는 메일이 스팸인지 예측한다.
예측 대상의 정답 값을 레이블, 예측에 사용하는 입력 정보를 특성이라고 한다.

머신러닝은 학습에 어떤 정보를 사용하는지에 따라 여러 방식으로 구분할 수 있다.
대표적인 학습 방식은 다음과 같다.

| 학습 방식 | 학습에 사용하는 정보 | 예시 |
| --- | --- | --- |
| 지도학습 | 입력과 정답 | 집값 예측, 스팸 여부 예측 |
| 비지도학습 | 정답 없이 주어진 데이터 | 구매 행동이 비슷한 고객끼리 묶기 |
| 준지도학습 | 일부 데이터의 정답과 정답 없는 데이터 | 정답이 표시된 일부 사진과 나머지 사진을 함께 활용 |
| 강화학습 | 환경에서 한 행동과 그에 따른 보상 | 게임에서 장기적으로 높은 보상을 얻는 행동 학습 |


K-means는 정답 그룹 없이 비슷한 데이터를 묶는 비지도학습 방법이다.
그림은 두 특성을 가진 설명용 데이터를 그룹 수를 세 개로 정해 묶은 결과다. 각 점은 데이터 한 개이며, 학습 후의 색은 나뉜 그룹을 나타낸다.

> 노트북 그림 · 같은 설명용 데이터를 K-means 학습 전에는 한 색으로, 학습 후에는 세 그룹의 색으로 표시한 결과

### 학습과 추론

학습은 데이터에 맞춰 모델 내부의 값을 조정하는 과정이다.
모델 내부에서 조정되는 값을 파라미터라고 한다.
지도학습에서는 예측과 정답의 차이를 줄이는 방향으로 파라미터를 조정한다.

추론은 학습된 모델에 새로운 입력을 넣어 결과를 얻는 과정이다.
스팸 예시로 모델을 만드는 것은 학습이고, 새로 받은 메일을 분류하는 것은 추론이다.

### 머신러닝은 언제 사용하는가

머신러닝은 규칙을 일일이 작성하기 어렵고, 문제와 관련된 데이터를 확보할 수 있을 때 유용하다.
특히 반복되는 판단이나 예측을 데이터에 근거해 수행할 때 사용한다.

예를 들어 주택 가격에는 면적, 위치, 건축 연도 등 여러 조건이 함께 영향을 준다.
과거 사례에서 이런 조건과 가격의 관계를 학습하는 모델을 사용할 수 있다.

평소와 크게 다른 거래나 설비 상태를 찾아내는 이상탐지에도 머신러닝을 활용한다.

### 딥러닝과 LLM

### 딥러닝은 무엇인가

딥러닝은 신경망을 사용하는 머신러닝 방법이다.
신경망은 입력된 숫자에 계산을 적용해 예측 등의 결과를 만드는 모델이다.
딥러닝에서는 이러한 계산을 여러 층으로 쌓아, 한 층의 결과가 다음 층의 입력으로 이어지도록 한다.

사진에서 고양이를 구분하려면 귀의 모양, 얼굴의 윤곽, 털의 무늬 같은 정보를 활용할 수 있다.
전통적인 머신러닝으로 사진을 분류할 때는 보통 사람이 이런 특징을 수치로 추출하는 방법을 설계하고, 모델은 추출된 특징을 입력받아 분류 기준을 학습한다.
사진마다 자세나 배경이 달라서, 구분에 필요한 특징을 사람이 모두 정하기는 어렵다.

딥러닝에서는 각 픽셀의 밝기나 색을 숫자로 입력하고, 신경망이 고양이를 구분하는 데 유용한 특징과 분류 기준을 함께 학습한다.
앞쪽 층에서는 선이나 경계에 반응하고, 뒤쪽 층에서는 이를 조합한 복잡한 형태에 반응하는 특징이 나타날 수 있다.

각 층의 계산에는 입력에 곱해지는 가중치라는 값이 사용된다.
학습 과정에서는 예측과 정답의 차이가 줄어들도록 가중치 등 모델 내부의 값을 조정한다.

> 노트북 그림 · 입력층, 여러 은닉층, 출력층으로 구성된 신경망 구조

### 딥러닝은 언제 사용하는가

딥러닝은 이미지, 텍스트, 음성 등 다양한 데이터를 다루는 데 사용된다.
사람이 구분이나 예측에 필요한 특징을 하나씩 정하기 어려울 때, 데이터에서 복잡한 패턴을 학습하는 데 유용하다.

| 데이터 | 활용 예 | 학습하는 정보의 예 |
| --- | --- | --- |
| 이미지 | 제품 사진에서 불량 찾기 | 불량을 구분하는 모양이나 질감 |
| 텍스트 | 문장 번역, 글 요약·생성 | 단어와 문장 사이의 관계, 문맥에 맞는 표현 |
| 음성 | 말소리를 글자로 바꾸기 | 소리의 변화와 문자 사이의 관계 |

이런 데이터는 각각 숫자로 표현해 신경망에 입력한다.

딥러닝 모델을 처음부터 학습하려면 많은 데이터와 계산 자원이 필요할 수 있다.
이미 학습된 모델을 가져와 목적에 맞게 추가로 학습하면 필요한 데이터와 학습 비용을 줄일 수 있다.
이처럼 먼저 학습한 지식을 다른 작업에 활용하는 것을 전이학습이라고 한다.

딥러닝을 사용할지는 데이터의 특성과 필요한 예측 성능, 학습과 실행에 드는 비용을 고려해 결정한다.
예를 들어 매출이나 고객 정보 같은 표 데이터에서는 선형 모델이나 트리 기반 모델로도 충분한 성능을 얻을 수 있다.

### LLM은 무엇인가

LLM은 대규모 언어 모델로, 많은 데이터와 큰 규모의 신경망으로 언어의 패턴을 학습한 딥러닝 모델이다.
텍스트는 토큰이라는 처리 단위로 나뉘며, 토큰은 단어나 단어의 일부 등이 될 수 있다.
텍스트를 생성하는 대표적인 LLM은 앞선 토큰들로 다음 토큰을 예측하도록 파라미터를 조정하며 언어의 패턴을 학습한다.
추론할 때는 입력된 문맥을 바탕으로 다음 토큰을 선택하고, 선택한 토큰을 문맥에 추가하는 과정을 반복해 문장을 만든다.

대표적인 LLM은 Transformer라는 신경망 구조를 사용한다.
Transformer는 문맥 속 입력 토큰 사이의 관계를 반영해 정보를 처리하는 구조다.

> ➕ **더 알아두기**

> K-means는 정답 레이블 없이 군집 내 거리를 줄이는 목적을 갖는다. 오토인코더는 사람이 붙인 레이블 없이 입력을 복원하도록 신경망을 학습한다. 사람은 입력 특징을 고르거나 원본 픽셀을 줄 수 있다. 은닉층은 입력과 최종 출력 사이의 층이다. 일반적인 완전연결층에서 층 수와 폭은 사람이 정하고 내부 가중치와 편향은 학습한다. 입력 2개와 뉴런 120개라면 가중치 240개와 편향 120개가 있으며, 출력 120개의 의미는 학습 과정에서 형성된다.
>
> ReLU는 가중치가 아니라 가중합에 편향을 더한 값 z에 max(0,z)를 적용한다. 음수는 오류라는 뜻이 아니다. 활성화 없이 아핀 변환만 이어 붙이면 하나의 아핀 변환으로 합쳐진다. 한 출력이 0이어도 다음 층은 나머지 출력과 편향을 사용한다. 예를 들어 [0,3]에 [2,4]를 곱해 더하고 편향 1을 더하면 13이다. 모든 입력이 0이면 활성화 이전 값은 편향이다. 특정 ReLU가 계속 음수 영역에 있으면 그 경로의 기울기가 0이 될 수 있다.
>
> 가중치는 각 입력이 예측에 반영되는 정도이고 편향은 기준값을 옮긴다. 초기값은 일반적으로 초기화 규칙으로 정하고, 학습하며 바꾼다. 역전파는 연쇄법칙으로 손실을 각 가중치에 대해 미분한다. x=2, w₁=3, w₂=4이고 출력 xw₁w₂=24, 정답 30이면 제곱오차는 36이다. 출력에 대한 기울기 −12에 중간 출력 6을 곱해 w₂의 기울기 −72를 얻는다. w₁의 기울기는 −12×4×2=−96이다. 가중치를 실제로 바꾸는 것은 최적화 단계다.

### @로 행렬 곱하기

행렬 곱은 왼쪽 행렬의 각 행과 오른쪽 행렬의 각 열에서 대응하는 값들을 곱해 더하는 연산이다. 그 합이 결과 행렬의 해당 행·열에 들어간다.
왼쪽 행렬의 열 수와 오른쪽 행렬의 행 수가 같아야 하며, 결과는 왼쪽의 행 수와 오른쪽의 열 수를 가진다.

$A$가 $m \times n$, $B$가 $n \times p$ 행렬이면 결과 $C$는 $m \times p$ 행렬이다.

$$
C = AB, \qquad c_{ij} = \sum_{k=1}^{n} a_{ik}b_{kj}
$$

$c_{ij}$는 결과의 $i$번째 행, $j$번째 열의 값이다. $\sum$는 $A$의 $i$번째 행과 $B$의 $j$번째 열에서 짝지은 $n$개 곱을 모두 더한다는 뜻이다.

> 노트북 그림 · 왼쪽 행렬의 행과 오른쪽 행렬의 열을 곱해 더하여 결과 행렬의 한 값을 만드는 과정

NumPy에서는 `@`로 행렬 곱을 계산한다. 모델에서 입력값에 가중치를 곱해 합산할 때 사용하는 계산이다.
`(3, 2) @ (2, 1)`의 결과는 `(3, 1)`이다.

```python
weights = np.array([[10], [20]])  # 각 입력값에 곱할 가중치
print("왼쪽 행렬:\n", matrix)
print("오른쪽 행렬:\n", weights)

result = matrix @ weights
print("행렬 곱 결과:\n", result)
print("모양:", matrix.shape, "@", weights.shape, "→", result.shape)
```

### 대화에서 다시 짚은 것

> ➕ **더 알아두기**
>
> Series는 인덱스가 붙은 1차원 값의 열이다. DataFrame은 행과 열이 있는 표다. df["age"]는 (n,)이고 df[["age"]]는 열 이름 목록으로 선택한 (n,1) 표다. 필터링한 표의 행 이름이 [2,5]라면 첫 행은 iloc[0] 또는 loc[2]로 찾는다. 라벨 슬라이스는 끝을 포함하고 위치 슬라이스는 끝을 제외한다.
>
> 학생 한 명의 [국어, 영어]에 [0.6, 0.4]를 각각 곱해 더하면 출력 하나를 얻는다. 학생을 행에 쌓고 출력 기준을 열에 배치하면 모든 학생과 모든 기준에 동일한 내적을 수행한다. (3,2) @ (2,10)은 학생 세 명의 출력이 각각 10개여서 (3,10)이다. 안쪽의 2는 대응하는 입력과 가중치의 수다. NumPy의 행렬곱으로 Python 반복문을 직접 작성하지 않고 계산할 수 있다.
>
> ♻️ 처음엔 (3,2)+(2,)의 2가 모든 칸에 더해지는 값이라고 이해했으나, (2,)는 길이 2인 배열이다. [10,20]을 더하면 각 행의 두 열에 각각 10과 20이 더해진다. 모든 칸에 2를 더하려면 스칼라 2를 더한다.

### 결정 트리는 무엇인가

결정 트리(Decision Tree)는 입력에 대한 질문을 차례로 따라가며 예측하는 모델이다. 질문의 답에 따라 경로가 나뭇가지처럼 갈라지는 구조여서 트리라고 부른다.
예를 들어 “꽃잎 길이가 기준값 이하인가?”로 꽃들을 두 그룹으로 나누고, 필요한 그룹에는 꽃잎 너비 같은 다른 질문을 이어 간다. 분류에서는 마지막에 도착한 그룹의 학습 사례 중 가장 많은 품종을 예측한다.

학습할 때는 품종이 잘 구분되도록 어떤 특성에 질문할지와 기준값을 데이터에서 정한다. 예측할 때는 학습한 질문에 새 꽃의 측정값을 대입해 경로를 따라간다.
결정 트리는 학습한 질문과 예측 경로를 그림으로 나타낼 수 있어, 어떤 조건을 거쳐 예측했는지 해석할 수 있다.

### 붓꽃 데이터 불러오기

Iris 데이터는 붓꽃 150송이의 꽃받침(sepal)과 꽃잎(petal)의 길이·너비(cm)를 담고 있다. 한 행은 꽃 한 송이다.
입력 `X`는 네 가지 측정값이고, 정답 `y`는 품종이다. 품종은 `setosa`, `versicolor`, `virginica`이며 각각 0, 1, 2로 표시한다.

```python
# as_frame=True: 입력은 DataFrame, 정답은 Series로 불러온다.
iris = load_iris(as_frame=True)
X, y = iris.data, iris.target

# shape: X는 (행 수, 특성 수), y는 (행 수,)
print("X:", X.shape, "y:", y.shape)
display(X.head())
print(dict(enumerate(iris.target_names)))
```

### 일반화와 데이터 분리

일반화는 학습에 쓰지 않은 사례에서도 유용한 예측을 하는 능력이다.
정답을 외운 학생을 같은 문제로만 평가하면 응용 능력을 알기 어렵듯, 학습에 사용한 데이터 점수만으로 새 사례의 성능을 판단할 수 없다.

| 구간 | 사용하는 작업 | 하면 안 되는 작업 |
| --- | --- | --- |
| 학습 | 모델·전처리 기준 학습 | 검증, 테스트 정보를 섞어 학습 |
| 검증 | 깊이·학습률 등 설정 선택 | 검증 정답으로 모델을 직접 학습한 뒤 같은 구간 평가 |
| 테스트 | 선택이 끝난 모델의 최종 평가 | 점수를 보고 설정을 반복 변경 |

최종 비율은 학습 60%, 검증 20%, 테스트 20%다.

```python
X_train_val, X_test, y_train_val, y_test = train_test_split(
    X, y,
    test_size=0.2,  # 분리해 남길 데이터의 비율
    stratify=y,  # 나뉜 데이터에서도 품종 비율을 유지한다.
    random_state=SEED,  # 같은 무작위 분리를 재현한다.
)

X_train, X_val, y_train, y_val = train_test_split(
    X_train_val, y_train_val, test_size=0.25, stratify=y_train_val, random_state=SEED)

print(len(X_train), len(X_val), len(X_test))
```

### 모델 학습과 예측

`DecisionTreeClassifier`는 scikit-learn의 결정 트리 분류 모델 클래스다.

정확도(accuracy)는 전체 사례 중 맞힌 비율이며, 0부터 1 사이의 값이다.

```python

model = DecisionTreeClassifier(max_depth=3, random_state=SEED)  # max_depth: 질문의 최대 깊이

# fit: 입력과 정답으로 모델의 분할 기준을 학습한다.
model.fit(X_train, y_train)

# predict: 학습한 모델에 입력만 전달해 각 행의 품종 번호를 예측한다.
# 반환값은 검증 행 수만큼의 예측을 담은 (30,) 배열이다.
prediction = model.predict(X_val)
print("검증 정확도:", accuracy_score(y_val, prediction))  # 정답, 예측 순서로 전달한다.

results = X_val.copy()
results["actual"] = iris.target_names[y_val]
results["predicted"] = iris.target_names[prediction]

# 실제 품종과 예측 품종이 다른 행만 확인한다.
display(results.loc[y_val != prediction])
```

### 파라미터와 하이퍼파라미터

파라미터는 학습으로 정해지는 값이고, 하이퍼파라미터는 학습 전에 지정하는 설정이다.
결정 트리가 학습한 질문이 `꽃잎 길이 ≤ 2.45`라면 기준값 `2.45`는 파라미터이고, 최대 깊이를 제한하는 `max_depth=3`은 하이퍼파라미터다.
하이퍼파라미터를 바꾸면 모델을 다시 학습한다.

### 결정 트리 그림 읽기

각 상자는 노드이며, 맨 위의 노드를 루트라고 한다. 질문으로 경로가 갈라지는 노드는 분기 노드, 더 이상 갈라지지 않는 끝은 잎(leaf)이다.
루트부터 질문의 조건을 확인해 참이면 왼쪽, 거짓이면 오른쪽으로 이동한다. `꽃잎 길이 ≤ 2.45`라면 길이가 2.45 이하일 때 왼쪽으로 간다. 도착한 잎의 `class`가 예측 품종이다.

질문할 특성과 기준값은 모델이 학습으로 정한다. `samples`와 `value`는 각 노드에 도달한 학습 사례를 세어 자동으로 계산하며, `class`는 가장 많은 품종으로 정한다.

- `samples`: 학습 사례 수
- `value`: 품종별 사례 수. `[0, 30, 1]`이면 `setosa` 0개, `versicolor` 30개, `virginica` 1개
- `class`: 사례 수가 가장 많은 품종. 동률이면 `value`의 순서에서 앞선 품종

깊이(depth)는 루트에서 해당 노드까지 거친 분할 횟수다. 루트의 깊이는 0이고, 한 단계 내려갈 때마다 1씩 늘어난다.

```python
plt.figure(figsize=(12, 5))
plot_tree(model, feature_names=list(X.columns), class_names=list(iris.target_names),
          filled=True, rounded=True, proportion=False, impurity=False)
plt.show()
```

### 트리 깊이 바꾸기

`max_depth`는 트리가 질문을 이어갈 수 있는 깊이를 제한한다.

같은 학습·검증 데이터로 깊이 2와 4인 모델을 학습하고, 기준 모델인 깊이 3과 트리 구조·학습 정확도·검증 정확도를 비교한다.

```python
experiment_log = {
    model.max_depth: {
        "max_depth": model.max_depth,
        "model": model,
        "train_accuracy": accuracy_score(y_train, model.predict(X_train)),
        "val_accuracy": accuracy_score(y_val, model.predict(X_val)),
    }
}

for depth in [2, 4]:
    practice_model = DecisionTreeClassifier(max_depth=depth, random_state=SEED)
    practice_model.fit(X_train, y_train)

    experiment_log[depth] = {
        "max_depth": depth,
        "model": practice_model,
        "train_accuracy": accuracy_score(y_train, practice_model.predict(X_train)),
        "val_accuracy": accuracy_score(y_val, practice_model.predict(X_val)),
    }

    plt.figure(figsize=(12, 5))
    plot_tree(practice_model, feature_names=list(X.columns), class_names=list(iris.target_names),
              filled=True, rounded=True, proportion=False, impurity=False)
    plt.title(f"max_depth = {depth}")
    plt.show()

display(pd.DataFrame(experiment_log.values())
        [["max_depth", "train_accuracy", "val_accuracy"]].sort_values("max_depth"))
```

### 정확도 비교

트리가 깊어지면 학습 데이터의 세세한 특징까지 반영할 수 있다. 학습 데이터의 우연한 패턴까지 학습해 새 데이터의 예측 성능이 떨어지는 현상을 과적합이라고 한다.

깊이를 늘렸을 때 학습 정확도는 높아지고 검증 정확도는 낮아지는지 살펴본다.

### 최종 테스트

검증 정확도가 가장 높았던 깊이 4를 선택하고, 테스트 데이터로 최종 정확도를 평가한다.

```python

test_prediction = final_model.predict(X_test)
```

### 전처리가 필요한 이유

전처리는 수집한 데이터를 모델이 사용할 수 있는 입력으로 정리하고 변환하는 작업이다.
빠진 값이나 잘못된 기록을 처리하고, 문자열과 서로 다른 단위의 숫자를 모델에 맞게 표현한다.

| 데이터의 상태 | 필요한 처리 |
| --- | --- |
| 같은 기록이 반복되거나 표기·단위가 섞임 | 중복 확인, 표기·단위 통일 |
| 값이 비어 있거나 잘못 기록됨 | 오류 확인, 삭제 또는 결측값 대체 |
| 숫자 열마다 단위와 크기가 다름 | 표준화 등 스케일링 |
| 섬 이름처럼 종류를 나타내는 문자열이 있음 | 원핫 인코딩 등 범주 표현 |

전처리 방법은 데이터의 상태와 처리 후 남는 정보를 고려해 선택한다. 결측값이 있는 행을 삭제할 때는 결측 비율과 남는 데이터의 양을 확인하고, 유난히 큰 값은 입력 오류인지 실제 관측값인지 살펴본다. 스케일링은 거리 기반 모델처럼 숫자 크기에 영향을 받는 모델에서 고려한다.
데이터에서 구한 대체값과 변환 기준은 학습 데이터로 정하고, 검증·테스트 데이터와 새 데이터에 그대로 적용한다.

### 학습·검증·테스트로 나누기

학습 데이터에서 전처리 기준을 구하고, 검증·테스트 데이터에는 그 기준을 적용한다.
검증·테스트 데이터까지 섞어서 평균이나 중앙값을 구하면, 평가에 쓸 데이터의 정보가 학습 과정에 들어가는 데이터 누수가 생긴다.

| 구분 | 역할 | 전처리 |
| --- | --- | --- |
| 학습 | 모델과 전처리 기준 학습 | 기준을 구하고 변환 |
| 검증 | 모델·전처리 설정 선택 | 학습 기준으로 변환 |
| 테스트 | 선택을 마친 모델의 최종 평가 | 학습 기준으로 변환 |

학습 60%, 검증 20%, 테스트 20%로 나눈다. 이 실습에서는 세 데이터의 전처리 결과를 확인한다.

`train_test_split`은 입력의 행을 무작위로 나눈다. 먼저 `test_size=0.2`로 테스트 데이터를 분리하고, 남은 80%에서 `test_size=0.25`로 전체의 20%를 검증용으로 분리한다.
`random_state=SEED`는 같은 무작위 분리를 재현하는 설정이다.

```python
# 전체 데이터에서 테스트용 20% 분리

# 남은 데이터에서 검증용을 분리해 학습 60%·검증 20%로 구성

    X_train_val, test_size=0.25, random_state=SEED,

print("학습 데이터:", X_train.shape)

```

### 전처리 도구의 공통 사용법

전처리 도구는 학습 데이터에서 기준을 구해 객체 안에 저장한다.
같은 객체로 검증·테스트 데이터와 새 데이터를 변환하면 학습할 때 정한 기준이 유지된다.

| 메서드 | 역할 | 결측값 대체 예시 |
| --- | --- | --- |
| `fit` | 기준 계산·저장 | 학습 데이터의 열별 중앙값 저장 |
| `transform` | 저장한 기준으로 변환 | 저장된 중앙값으로 결측값 대체 |
| `fit_transform` | 기준 계산·저장 후 변환 | 중앙값 저장 후 학습 결측값 대체 |

### 중앙값으로 결측값 채우기

`SimpleImputer`는 열별로 정한 대표값이나 고정값으로 결측값을 채우는 전처리 클래스다.
중앙값은 값을 크기순으로 정렬했을 때 가운데 값이며, 개수가 짝수이면 가운데 두 값의 평균이다. 평균보다 극단값의 영향을 덜 받는다.

몸무게와 날개 길이의 결측값을 학습 데이터에서 구한 각 열의 중앙값으로 채울 수 있다.

`strategy="median"`은 중앙값 대체를 지정한다. `fit_transform`은 학습 중앙값을 저장하고 학습 데이터를 변환하며, `transform`은 저장된 중앙값으로 검증·테스트 데이터를 변환한다.
반환값은 NumPy 배열로, 학습 결과는 `(206, 2)`, 검증·테스트 결과는 각각 `(69, 2)`다.

`imputer.statistics_`에서 입력 열 순서로 저장된 대체값을 확인할 수 있다.

```python
# 학습 데이터의 중앙값으로 학습·검증·테스트 데이터의 빈칸 채우기
imputer = SimpleImputer(strategy="median")
train_filled = imputer.fit_transform(X_train[numeric_columns])
val_filled = imputer.transform(X_val[numeric_columns])
test_filled = imputer.transform(X_test[numeric_columns])

# 저장된 대체값 확인
display(pd.Series(imputer.statistics_, index=numeric_columns, name="학습 중앙값"))

# 몸무게가 비어 있던 행의 대체 전후 비교
train_filled_df = pd.DataFrame(train_filled, columns=numeric_columns, index=X_train.index)
missing_rows = X_train["body_mass_g"].isna()
print("빈칸을 채우기 전")
display(X_train.loc[missing_rows, numeric_columns])
print("빈칸을 채운 후")
display(train_filled_df.loc[missing_rows, numeric_columns])
```

### 숫자의 크기를 맞추는 표준화

몸무게의 4,000g과 날개 길이의 200mm는 단위와 숫자의 크기가 다르다.
거리 기반 모델에서는 숫자 크기가 큰 열이 거리 계산에 더 큰 영향을 줄 수 있다.
표준화는 각 값을 평균에서 표준편차 몇 개만큼 떨어져 있는지로 바꾼다.

```text
변환값 = (원래 값 - 평균) / 표준편차
```

표준편차는 값들이 평균 주변에 얼마나 퍼져 있는지를 나타낸다.
`StandardScaler`는 학습 데이터의 열별 평균과 표준편차를 저장하고, 그 기준으로 표준화하는 전처리 클래스다.

`scaler.mean_`에는 학습 데이터의 열별 평균이, `scaler.scale_`에는 표준화에 사용한 열별 표준편차가 저장된다.

```python
# 학습 데이터에서 구한 기준으로 학습·검증·테스트 데이터 표준화
scaler = StandardScaler()
train_scaled = scaler.fit_transform(train_filled)
val_scaled = scaler.transform(val_filled)
test_scaled = scaler.transform(test_filled)

# 표준화 기준과 변환 전후 값 확인
display(pd.DataFrame({"평균": scaler.mean_, "표준편차": scaler.scale_},
                     index=numeric_columns))
print("표준화 전")
display(train_filled_df.head())
print("표준화 후")
display(pd.DataFrame(train_scaled, columns=numeric_columns, index=X_train.index).head())
```

### 표준화 결과 읽기

변환값이 음수이면 원래 측정값이 학습 평균보다 작다는 뜻이다. 0은 학습 평균과 같고, 1은 학습 평균보다 표준편차 한 개만큼 크다는 뜻이다.

변환한 학습 데이터의 열별 평균은 약 0, 표준편차는 약 1이다.
검증·테스트 데이터는 학습 데이터의 기준으로 변환하므로 평균이 0에서 벗어날 수 있다. 세 데이터의 평균을 비교한다.

NumPy 배열의 `mean()`은 평균, `std()`는 표준편차를 계산한다. `axis=0`으로 지정하면 각 열을 따로 계산해 1차원 배열로 반환한다.

```python
# 표준화 후 학습·검증·테스트 데이터의 열별 통계 비교
display(pd.DataFrame({
    "변환 후 학습 평균": train_scaled.mean(axis=0),
    "변환 후 학습 표준편차": train_scaled.std(axis=0),
    "변환 후 검증 평균": val_scaled.mean(axis=0),
    "변환 후 테스트 평균": test_scaled.mean(axis=0),
}, index=numeric_columns).round(4))
```

### 섬 이름을 숫자로 표현하기

섬 이름처럼 종류를 나타내는 값을 범주라고 하고, 범주를 숫자로 표현하는 작업을 인코딩이라고 한다.

원핫 인코딩은 범주마다 열을 만들고 해당하면 1, 아니면 0을 넣는 방법이다.
`OneHotEncoder`는 학습 데이터의 범주 목록을 저장하고, 같은 열 순서로 인코딩하는 전처리 클래스다.

| 섬 | Biscoe | Dream | Torgersen |
| --- | --- | --- | --- |
| Biscoe | 1 | 0 | 0 |
| Dream | 0 | 1 | 0 |
| Torgersen | 0 | 0 | 1 |

| 설정·메서드 | 역할 |
| --- | --- |
| `handle_unknown="ignore"` | 학습 때 없던 섬은 섬을 나타내는 열을 모두 0으로 처리 |
| `sparse_output=False` | 희소 행렬 대신 일반 NumPy 배열로 반환 |
| `get_feature_names_out()` | 입력 열과 범주 이름으로 만든 출력 열 이름 반환 |

섬 세 종류를 인코딩한 배열의 모양은 학습 `(206, 3)`, 검증·테스트 각각 `(69, 3)`이다.

```python
# 학습 데이터의 섬 목록으로 학습·검증·테스트 데이터 인코딩
encoder = OneHotEncoder(
    handle_unknown="ignore",
    sparse_output=False,
)
train_encoded = encoder.fit_transform(X_train[category_columns])
val_encoded = encoder.transform(X_val[category_columns])
test_encoded = encoder.transform(X_test[category_columns])
encoded_columns = encoder.get_feature_names_out()

# 원래 섬 이름과 인코딩 결과 비교
island_result = pd.DataFrame(train_encoded, columns=encoded_columns, index=X_train.index)
island_result["원래 섬"] = X_train["island"]
display(island_result.head())
```

### 숫자로 표현하는 이유

문자열을 직접 계산할 수 없는 모델에 섬 정보를 입력하려면 인코딩이 필요하다.

`Biscoe=1`, `Dream=2`, `Torgersen=3`으로 번호를 붙이면 Biscoe와 Dream의 차이는 1, Biscoe와 Torgersen의 차이는 2가 된다.
거리 기반 모델은 Biscoe를 Torgersen보다 Dream에 가깝게 취급하지만, 섬 이름에는 이 순서와 간격의 의미가 없다.
원핫 인코딩은 임의의 순서나 간격 대신 각 범주에 해당하는지를 표현한다.

### 변환 결과 합치기

표준화한 숫자 두 열과 섬을 나타내는 세 열을 합치면 입력 세 열이 숫자 다섯 열로 바뀐다.
행 인덱스를 유지해 각 값이 어느 펭귄의 기록인지 맞춘다.
학습·검증·테스트 데이터의 열 이름과 순서가 같고, 결측값이 남지 않았는지 확인한다.

`isna().sum().sum()`에서 첫 번째 `sum()`은 열별 결측값 수를 구하고, 두 번째 `sum()`은 이를 합쳐 표 전체의 결측값 수를 구한다.

```python
# 숫자 열과 섬 인코딩 결과를 합쳐 학습·검증·테스트 입력 구성
train_input = pd.DataFrame(train_scaled, columns=numeric_columns, index=X_train.index)
train_input[encoded_columns] = train_encoded
val_input = pd.DataFrame(val_scaled, columns=numeric_columns, index=X_val.index)
val_input[encoded_columns] = val_encoded
test_input = pd.DataFrame(test_scaled, columns=numeric_columns, index=X_test.index)
test_input[encoded_columns] = test_encoded

# 완성된 입력의 크기와 일부 행 확인
print("학습 입력:", train_input.shape)
display(train_input.head())
print("검증 입력:", val_input.shape)
display(val_input.head())
print("테스트 입력:", test_input.shape)
display(test_input.head())

# 열 이름·순서와 남은 결측값 수 확인
print("열 이름과 순서가 같은가:",
      train_input.columns.equals(val_input.columns)
      and train_input.columns.equals(test_input.columns))
print("남은 빈칸 수(학습, 검증, 테스트):",
      train_input.isna().sum().sum(),
      val_input.isna().sum().sum(),
      test_input.isna().sum().sum())
```

### 파이프라인으로 연결하기

### 파이프라인이 필요한 이유

여러 전처리를 따로 호출하면 중간 결과를 전달하고, 열별 결과를 직접 합쳐야 한다.
새 데이터에도 같은 처리를 반복할 때 단계를 빠뜨리거나 순서를 바꾸기 쉽다.

파이프라인은 처리 단계를 정해진 순서로 연결한 것이다.
각 단계에서 학습한 기준과 처리 순서를 검증·테스트 데이터와 새 데이터에도 일관되게 적용한다.

### Pipeline으로 처리 순서 묶기

`Pipeline`은 여러 처리 도구를 순서대로 연결하는 클래스다. 앞 단계의 변환 결과가 다음 단계의 입력이 된다.
숫자 열은 결측값을 채운 뒤 표준화한다.

각 단계는 `(이름, 처리 도구)`로 지정한다. 객체를 만들 때는 순서만 정하고, `fit` 또는 `fit_transform`을 호출할 때 기준을 학습한다.

```python
# 숫자 열의 결측값 대체와 표준화를 순서대로 연결
numeric_pipeline = Pipeline([
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", StandardScaler()),
])
```

### ColumnTransformer로 열별 처리 연결하기

`ColumnTransformer`는 열별로 지정한 전처리를 적용하고, 결과를 옆으로 합치는 클래스다.
숫자 열에는 결측값 대체와 표준화를, 섬 열에는 원핫 인코딩을 적용한다.

| 입력 | 처리 | 출력 열 수 |
| --- | --- | --- |
| 몸무게·날개 길이 | 중앙값 대체 → 표준화 | 2 |
| 섬 이름 | 원핫 인코딩 | 3 |

`Pipeline`은 처리 순서를, `ColumnTransformer`는 열별 처리를 묶는다.

각 항목은 `(이름, 처리 도구, 열 목록)`으로 지정하며, 변환 결과는 목록에 적은 순서대로 합쳐진다.

```python
# 숫자 열과 섬 열에 적용할 처리를 하나로 묶기
preprocessor = ColumnTransformer([
    ("numeric", numeric_pipeline, numeric_columns),
    ("category", OneHotEncoder(handle_unknown="ignore", sparse_output=False), category_columns),
])
```

### 학습·검증·테스트 데이터 변환하기

학습 데이터로 각 전처리 기준을 정하고 변환한다. 검증·테스트 데이터는 저장된 기준으로 변환한다.
파이프라인으로 묶어도 검증·테스트 데이터에 `fit_transform`을 호출하면 기준을 다시 계산하므로 데이터 누수가 생긴다.

`get_feature_names_out()`으로 최종 열 이름을 확인한다. 이름 앞의 `numeric__`와 `category__`는 해당 열을 만든 처리 묶음이다.

```python
# 학습 데이터로 기준을 정하고 학습·검증·테스트 데이터를 변환
train_ready = preprocessor.fit_transform(X_train)
val_ready = preprocessor.transform(X_val)
test_ready = preprocessor.transform(X_test)

# 변환 전후 크기와 최종 열 이름 확인
print("학습 입력:", X_train.shape, "→", train_ready.shape)
print("검증 입력:", X_val.shape, "→", val_ready.shape)
print("테스트 입력:", X_test.shape, "→", test_ready.shape)
feature_names = preprocessor.get_feature_names_out()
display(pd.DataFrame(train_ready, columns=feature_names, index=X_train.index).head())
```

### 개별 전처리와 결과 비교

개별 전처리와 파이프라인은 같은 학습 데이터와 설정을 사용하므로 변환 결과가 같아야 한다.
숫자 두 열과 섬 세 열이 합쳐져 학습 입력은 `(206, 5)`, 검증·테스트 입력은 각각 `(69, 5)`가 된다.

세 비교 결과가 모두 `True`이고 결측값이 0개인지 확인한다.

`np.allclose`는 두 결과의 숫자가 작은 부동소수점 오차를 제외하고 같으면 `True`를 반환한다.

```python
# 개별 전처리와 파이프라인의 결과 및 남은 결측값 비교
print("학습 결과가 같은가:", np.allclose(train_input, train_ready))
print("검증 결과가 같은가:", np.allclose(val_input, val_ready))
print("테스트 결과가 같은가:", np.allclose(test_input, test_ready))
print("검증 결과에 남은 빈칸 수:", pd.DataFrame(val_ready).isna().sum().sum())
print("테스트 결과에 남은 빈칸 수:", pd.DataFrame(test_ready).isna().sum().sum())
```

### 새 관측값도 한 번에 변환하기

몸무게가 비어 있는 펭귄 한 마리의 기록을 만들고, 학습 데이터로 기준을 정한 파이프라인으로 변환한다.
`np.nan`은 숫자 데이터의 결측값을 나타낸다.
입력 한 행이 다섯 열로 변환되고, 결측값이 채워졌는지 확인한다.

```python
# 몸무게가 비어 있는 새 관측값 준비
new_penguin = pd.DataFrame({
    "body_mass_g": [np.nan],
    "flipper_length_mm": [200.],
    "island": ["Dream"],
})

# 저장된 전처리로 새 관측값 변환
new_ready = preprocessor.transform(new_penguin)

# 원본과 변환 결과, 남은 결측값 확인
display(new_penguin)
display(pd.DataFrame(new_ready, columns=feature_names))
print("새 입력의 모양:", new_ready.shape)
print("남은 빈칸 수:", pd.DataFrame(new_ready).isna().sum().sum())
```

### 펭귄 데이터의 전처리 방법 비교

### 결측값이 있는 행 삭제하기

펭귄 학습 데이터 `X_train`에서 결측값이 있는 행을 삭제하면 관측 수가 줄고, 특정 유형의 관측이 더 많이 빠질 수 있다.

삭제 기준별로 남은 행 수를 비교한다. 숫자 두 열에서 같은 행이 비어 있으므로 전체 열을 기준으로 행을 삭제해도, 몸무게만 기준으로 삭제해도 남는 행은 같다.

| 코드 | 삭제 대상 |
| --- | --- |
| `dropna()` | 결측값이 하나라도 있는 행 |
| `dropna(subset=["body_mass_g"])` | 몸무게가 비어 있는 행 |

```python
# 전체 열 또는 몸무게를 기준으로 결측 행 삭제
train_complete_rows = X_train.dropna()
train_mass_present = X_train.dropna(subset=["body_mass_g"])

# 삭제 기준별 남은 행과 열 수 비교
deletion_summary = pd.DataFrame(
    [X_train.shape, train_complete_rows.shape, train_mass_present.shape],
    index=["원본", "결측 행 삭제", "몸무게 결측 행 삭제"],
    columns=["행 수", "열 수"],
)
display(deletion_summary)
```

### 결측값 채우는 방법 비교하기

대체 방법에 따라 결측값에 들어가는 숫자가 달라진다.

| 방법 | 채우는 값 | 고려할 점 |
| --- | --- | --- |
| 평균 | 관측된 숫자의 평균 | 극단값의 영향을 받음 |
| 중앙값 | 크기순으로 가운데 값 | 평균보다 극단값의 영향을 덜 받음 |
| 최빈값 | 가장 자주 등장한 값 | 숫자와 범주에 사용 가능 |
| 고정값 | 지정한 값 | 값의 의미를 데이터에 맞게 정해야 함 |

펭귄 학습 데이터의 같은 몸무게 결측값에 네 방법을 적용해 대체값을 비교한다. 

`strategy`에는 평균 `"mean"`, 중앙값 `"median"`, 최빈값 `"most_frequent"`, 고정값 `"constant"`를 지정한다. 고정값은 `fill_value`로 정한다.

`X_train[["body_mass_g"]]`는 한 열을 2차원 DataFrame으로 선택한다. 변환 결과의 `[:, 0]`은 모든 행에서 첫 열을 꺼내 1차원 배열로 만든다.

```python
# 비교할 네 가지 결측값 대체 방법 준비
imputation_methods = {
    "평균": SimpleImputer(strategy="mean"),
    "중앙값": SimpleImputer(strategy="median"),
    "최빈값": SimpleImputer(strategy="most_frequent"),
    "고정값": SimpleImputer(strategy="constant", fill_value=4000),
}

# 같은 학습 데이터에 각 방법을 적용해 결과 모으기
imputation_comparison = pd.DataFrame({"원래 몸무게": X_train["body_mass_g"]})
for name, method in imputation_methods.items():
    filled_mass = method.fit_transform(X_train[["body_mass_g"]])
    imputation_comparison[name] = filled_mass[:, 0]

# 몸무게가 비어 있던 행의 대체값 비교
display(imputation_comparison.loc[missing_rows].round(2))
```

### 스케일링 방법 비교

스케일링은 숫자의 크기나 범위를 조절하는 작업이다. 전처리 클래스마다 기준이 다르다.

| 클래스 | 변환 방법 | 특징 |
| --- | --- | --- |
| `StandardScaler` | `(값 - 평균) / 표준편차` | 학습 데이터의 평균을 0, 표준편차를 1로 맞춘다. |
| `MinMaxScaler` | `(값 - 최솟값) / (최댓값 - 최솟값)` | 학습 데이터의 최솟값을 0, 최댓값을 1로 맞춘다. |
| `RobustScaler` | `(값 - 중앙값) / IQR` | 중앙값과 IQR을 사용해 극단값의 영향을 덜 받는 기준으로 변환한다. |

IQR은 75% 지점의 값에서 25% 지점의 값을 뺀 것으로, 가운데 50%가 퍼진 범위다.

펭귄 학습 데이터의 결측값을 중앙값으로 채운 `train_filled`에 세 방법을 적용한다. 같은 몸무게가 각 방법에서 어떤 값으로 바뀌는지 비교한다.

```python
# 비교할 스케일링 도구 준비
scaling_methods = {
    "StandardScaler": StandardScaler(),
    "MinMaxScaler": MinMaxScaler(),
    "RobustScaler": RobustScaler(),
}

# 각 도구로 학습·검증 데이터 변환
scaled_train_results = {}
scaled_val_results = {}
for name, method in scaling_methods.items():
    scaled_train_results[name] = method.fit_transform(train_filled)
    scaled_val_results[name] = method.transform(val_filled)

# 같은 몸무게의 변환 결과 비교
scaling_comparison = pd.DataFrame({"원래 몸무게": train_filled[:, 0]}, index=X_train.index)
for name, result in scaled_train_results.items():
    scaling_comparison[name] = result[:, 0]
```


### 이상치 후보 확인하기

이상치는 다른 관측값과 비교해 유난히 크거나 작은 값이다. 입력 오류인지, 실제로 드문 관측인지 원인을 확인한 뒤 처리한다.
값을 정렬했을 때 25% 지점을 `Q1`, 75% 지점을 `Q3`라고 한다. 두 값의 차이인 IQR은 가운데 50%가 퍼진 범위다.
`Q1 - 1.5 × IQR`보다 작거나 `Q3 + 1.5 × IQR`보다 큰 값을 확인 대상으로 표시할 수 있다.

정리한 구매 기록에서 금액이 있는 행만 선택해 경계를 계산하고, 경계를 벗어난 기록을 표시한다.
`quantile(0.25)`와 `quantile(0.75)`는 각각 25%, 75% 지점의 값을 구한다.

```python
# 금액이 있는 구매 기록으로 이상치 확인 경계 계산
amount_check = clean_sales[["purchase_id", "amount_won"]].dropna().copy()
q1 = amount_check["amount_won"].quantile(0.25)
q3 = amount_check["amount_won"].quantile(0.75)
iqr = q3 - q1
lower_bound = q1 - 1.5 * iqr
upper_bound = q3 + 1.5 * iqr
print("확인 경계:", lower_bound, "~", upper_bound)

# 경계를 벗어난 구매 기록을 확인 대상으로 표시
amount_check["확인 필요"] = (
    (amount_check["amount_won"] < lower_bound)
    | (amount_check["amount_won"] > upper_bound)
)
display(amount_check)
```

### 이상치를 확인한 뒤 처리하기

| 확인 결과 | 처리 방법 |
| --- | --- |
| 단위나 입력 오류이며 원래 값을 확인할 수 있음 | 올바른 값으로 수정 |
| 오류는 확인했지만 원래 값을 알 수 없음 | 결측값으로 바꾼 뒤 대체하거나, 분석 목적에 따라 행 제외 |
| 실제로 관측된 큰 값 | 값을 유지하고 분석 목적에 맞는 변환 검토 |

경계를 벗어났다는 이유만으로 기록을 삭제하지 않는다.
이 예제에서는 200,000원이 실제 구매 금액이라고 가정하고 유지한다.

### 로그 변환으로 큰 값의 격차 줄이기

구매 금액처럼 대부분은 작고 일부 값만 매우 큰 데이터에는 로그 변환을 고려할 수 있다.
로그 변환은 값이 커질수록 증가 폭을 줄여 큰 값 사이의 격차를 압축한다.

`np.log1p(x)`는 자연로그 `log(1 + x)`를 계산한다.
금액이 확인된 구매 기록에 적용하고, 원 단위 금액과 변환값을 비교한다.

```python
# 금액이 확인된 구매 기록에 로그 변환 적용
log_result = amount_check[["purchase_id", "amount_won"]].copy()
log_result["log_amount"] = np.log1p(log_result["amount_won"])

# 원래 구매 금액과 로그 변환값 비교
display(log_result.round(3))
```

### 로그 변환 결과 해석

200,000원인 구매 기록도 남아 있지만, 로그 변환 후에는 다른 금액과의 숫자 격차가 줄어든다.
변환값은 원 단위 금액이 아니라 로그 값이며, 구매 금액의 크기 순서는 유지된다.

### 대화에서 다시 짚은 것

> ➕ **더 알아두기**
>
> 원핫 인코딩에서 세 칸은 범주별 표시등이다. [1,0,0], [0,1,0], [0,0,1]은 순서를 부여하지 않는다. 비트 조합으로 더 많은 범주를 표현하는 방식도 있지만 모델이 받는 값의 관계가 달라진다. 범주를 직접 지정해도 Biscoe와 biscoe는 다른 문자열이다. 공백과 대소문자를 먼저 통일하고, handle_unknown="ignore"이면 미등록 범주는 해당 열 묶음에서 모두 0으로 바뀐다.
>
> 평균 대체의 fit은 훈련 데이터에서 평균을 구해 기억하고, transform은 그 평균으로 실제 빈칸을 채운다. 검증과 테스트도 훈련 평균을 사용한다. 전처리에서 전체 평균을 먼저 구하면 평가 데이터에서 얻은 정보가 학습에 들어간다. Pipeline은 작업 순서를 묶고 ColumnTransformer는 열에 따라 다른 작업을 적용한다.
>
> ♻️ 처음엔 IQR이 RobustScaler라고 이해했으나, IQR은 Q3−Q1이고 RobustScaler는 보통 중앙값을 빼고 IQR로 나눈다. Q1−1.5×IQR과 Q3+1.5×IQR 바깥은 별도의 이상치 후보 규칙이다.
>
> Auto MPG 대화 예시에서는 mpg를 y로 떼고 X와 함께 테스트 20%를 분리한다. 남은 데이터의 25%가 검증이므로 전체 기준으로 60:20:20이다. 수치 열에는 결측 대체와 스케일링, 범주 열에는 대체와 원핫 인코딩을 적용한다. 훈련만 fit한 후 검증과 테스트를 transform하고 열 수와 결측 여부를 확인한다. 이 예제는 설명을 확인했으며 실습 실행 결과는 확인하지 않았다.

### 회귀란 무엇인가

회귀(regression)는 입력 변수와 수치형 목표 변수 사이의 관계를 분석하고, 그 관계를 바탕으로 값을 예측하는 방법이다.

| --- | --- |

### 회귀 모델은 어떻게 학습할까

모델에 제공하는 정보를 입력 `X`, 예측하려는 실제 수치값을 정답 `y`라고 한다. 입력과 정답이 짝지어진 데이터로 학습하는 방식을 지도학습이라고 한다.

회귀 모델은 학습 데이터의 예측값과 정답 사이의 오차가 작아지도록 입력과 정답의 관계를 학습한다. 학습한 모델에 새로운 입력을 전달하면 수치형 예측값을 계산한다.

```text
학습: 입력 X + 정답 y → 입력과 정답의 관계 학습
예측: 새로운 입력 X → 학습한 모델 → 수치형 예측값
```

### 펭귄 몸무게 예측

### 선형 회귀의 기울기와 절편

입력이 날개 길이 하나라면 선형 회귀는 다음 식으로 예측한다.

```text
예측 몸무게 = 기울기 × 날개 길이 + 절편
```

기울기는 입력이 1만큼 증가할 때 예측값이 얼마나 변하는지를 나타낸다. 기울기가 50이라면 날개 길이가 1mm 증가할 때 예측 몸무게가 50g 증가한다.

절편(intercept)은 입력이 0일 때 식이 계산하는 예측값이다. 직선식 `y = ax + b`에서 `b`에 해당하며, 직선이 y축과 만나는 지점의 y값이므로 y절편이라고도 한다. 기울기를 고정한 채 절편을 키우면 직선 전체가 위로, 줄이면 아래로 이동한다. 절편은 관측한 데이터에 맞게 예측 직선의 높이를 조정하는 역할을 한다.

### 잔차와 MSE

잔차는 실제값에서 예측값을 뺀 값이다.
MSE(평균 제곱 오차)는 잔차를 제곱한 뒤 평균 낸 값이다. 양수와 음수 잔차가 서로 상쇄되지 않도록 제곱하며, 값이 작을수록 예측이 실제값에 가깝다.

$n$은 사례 수, $y_i$는 $i$번째 사례의 실제값, $\hat{y}_i$는 예측값이다. $\sum_{i=1}^{n}$은 첫 번째부터 $n$번째 사례까지 모두 더한다는 뜻이다.

$$
\mathrm{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

즉, 각 사례의 잔차를 제곱하고 모두 더한 뒤 사례 수로 나눈다. 몸무게의 단위가 g이면 MSE의 단위는 g²이다.

> 노트북 그림 · 선형 회귀 직선과 관측값 사이의 차이

### 선형 회귀의 손실 함수

손실 함수(loss function)는 학습할 때 예측 오차를 수치로 나타내는 함수다. 선형 회귀에서는 MSE를 손실 함수로 사용한다.

$x_i$는 $i$번째 펭귄의 날개 길이, $w$는 기울기, $b$는 절편이다. 예측식 $\hat{y}_i=wx_i+b$를 MSE 식에 넣으면 다음과 같다.

$$
L(w,b)=\frac{1}{n}\sum_{i=1}^{n}\bigl(y_i-(wx_i+b)\bigr)^2
$$

$L(w,b)$는 기울기와 절편을 정했을 때 계산되는 손실이다. 학습 데이터의 $x_i$와 $y_i$는 고정되어 있고, 모델은 $L(w,b)$가 가장 작아지는 $w$와 $b$를 찾는다.

### 모델 학습과 예측

`LinearRegression`에 날개 길이와 몸무게를 전달하면 예측 직선의 기울기와 절편을 구한다.  
입력 변수가 하나인 선형 회귀를 단순 선형 회귀라고 한다.

```python
simple_model = LinearRegression()
# fit: 2차원 입력 X와 1차원 정답 y로 모델을 학습한다.
simple_model.fit(X_train, y_train)
# predict: 검증 입력의 각 행에 대한 예측값을 (검증 행 수,) 배열로 반환한다.
simple_val_prediction = simple_model.predict(X_val)

# coef_: 입력 열별 가중치 배열, intercept_: 절편 값
print("기울기(g/mm):", simple_model.coef_[0])
print("절편(g):", simple_model.intercept_)
display(pd.DataFrame({
    "flipper_length_mm": X_val["flipper_length_mm"],
    "actual_g": y_val,
    "predicted_g": simple_val_prediction,
}).head())
```

### MAE와 RMSE

평가 지표는 모델의 예측이 얼마나 좋은지 비교하는 기준이다.

- MAE: 잔차의 절댓값을 평균 낸 값이다.
- RMSE: 제곱 오차 평균의 양의 제곱근이다. 큰 오차에 더 민감하게 반응한다.

두 지표 모두 정답과 같은 단위로 읽고 작을수록 좋다. 선형 회귀는 제곱 오차로 학습하지만 모델 비교에는 MAE도 사용할 수 있다.

학습 데이터의 처음 세 마리에 대한 실제 몸무게와 모델 예측값으로 MAE와 RMSE를 계산한다.

```python
small_X = X_train.head(3)
# 선택한 입력과 같은 행의 실제 몸무게를 가져온다.
actual_small = y_train.loc[small_X.index].to_numpy()
predicted_small = simple_model.predict(small_X)
error = actual_small - predicted_small

display(pd.DataFrame({
    "flipper_length_mm": small_X["flipper_length_mm"],
    "actual_g": actual_small,
    "predicted_g": predicted_small,
    "residual_g": error,
    "absolute_error_g": np.abs(error),
}))
print("MAE(g):", np.abs(error).mean())
print("RMSE(g):", np.sqrt((error ** 2).mean()))
```

### 결정계수 R²

결정계수 $R^2$는 모델의 제곱 오차를, 모든 사례를 실제값의 평균으로 예측했을 때의 제곱 오차와 비교하는 지표다.
MAE·RMSE는 실제 단위로 오차 크기를 나타내고, R²는 평균 예측을 기준으로 제곱 오차를 줄인 비율을 나타낸다.

$$
R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}
{\sum_{i=1}^{n}(y_i-\bar{y})^2}
$$

$n$은 평가 사례 수, $y_i$는 실제값, $\hat{y}_i$는 모델 예측값이다. $\bar{y}$는 평가하는 데이터의 실제값 평균이다.
검증 R²를 계산할 때는 검증 정답의 평균을, 테스트 R²를 계산할 때는 테스트 정답의 평균을 비교 기준으로 쓴다.
분자는 모델의 제곱 오차 합이고, 분모는 실제값의 평균으로 예측한 제곱 오차 합이다. 이 식은 실제값에 변동이 있어 분모가 0보다 클 때 적용한다.

| R² | 의미 |
| --- | --- |
| 1 | 모든 예측값이 실제값과 일치한다 |
| 0 | 평균으로 예측한 기준과 제곱 오차가 같다 |
| 음수 | 평균으로 예측한 기준보다 제곱 오차가 크다 |

R²는 단위가 없으며, 같은 평가 데이터에서 값이 클수록 좋다. 예를 들어 R²가 0.8이면 평균 예측 기준보다 제곱 오차를 80% 줄였다는 뜻이다.

### 학습·검증 평가 결과 기록

학습 RMSE·R²와 검증 RMSE·MAE·R²를 계산하고 `model_results`에 모델 이름별로 저장한다.
학습 오차와 검증 오차를 비교해 학습에 사용하지 않은 데이터에서도 잘 예측하는지 확인한다.

```python
# r2_score: (사례 수,) 모양의 실제값과 예측값을 받아 R²를 실수로 반환한다.
model_results["simple"] = {
    "model": "simple",
    "train_RMSE_g": np.sqrt(mean_squared_error(y_train, simple_model.predict(X_train))),
    "val_RMSE_g": np.sqrt(mean_squared_error(y_val, simple_val_prediction)),
    "val_MAE_g": mean_absolute_error(y_val, simple_val_prediction),
    "train_R2": r2_score(y_train, simple_model.predict(X_train)),
    "val_R2": r2_score(y_val, simple_val_prediction),
}
model_comparison = pd.DataFrame(model_results.values())
display(model_comparison)
```

### 다항 회귀

### 다항 회귀는 무엇인가

날개 길이와 몸무게의 관계가 직선에서 벗어나 휘어 있다면, 직선 하나로는 그 형태를 충분히 표현하기 어렵다. 다항 회귀는 입력의 제곱·세제곱 등을 이용해 곡선 관계를 표현한다.
날개 길이를 `x`라고 할 때 2차 다항 회귀의 예측식은 다음과 같다.

```text
예측 몸무게 = 가중치₁ × x + 가중치₂ × x² + 절편
```

차수는 사용하는 항에서 가장 큰 지수다. 2차는 `x`와 `x²`, 3차는 `x`, `x²`, `x³`을 사용한다. 새 측정값을 추가하는 것이 아니라 같은 날개 길이에서 입력 특성을 만든다.
다항 회귀는 입력의 제곱·세제곱 등을 새로운 특성으로 만들고, 선형 회귀로 학습해 곡선 관계를 표현한다.

### 다항 특성 만들기

`PolynomialFeatures`는 입력에서 다항 특성을 만드는 변환기다. 날개 길이 하나를 2차로 변환하면 날개 길이와 그 제곱을 담은 두 열이 만들어진다.

```python
POLYNOMIAL_DEGREE = 2
# degree: 최대 차수. include_bias=False: 상수 1인 열을 만들지 않는다.
# 절편은 LinearRegression에서 구한다.
polynomial_features = PolynomialFeatures(degree=POLYNOMIAL_DEGREE, include_bias=False)
# fit_transform: 학습 입력에 맞춰 변환기를 설정하고 다항 특성 배열을 반환한다.
X_train_poly = polynomial_features.fit_transform(X_train)
# transform: 같은 변환기로 검증 입력을 변환한다.
X_val_poly = polynomial_features.transform(X_val)

print("변환 전:", X_train.shape, "변환 후:", X_train_poly.shape)
display(pd.DataFrame(
    X_train_poly[:3],
    columns=polynomial_features.get_feature_names_out(),  # 생성된 특성의 이름
))
```

### 다항 특성 표준화

거듭제곱으로 열의 크기 차이가 커지므로, 만든 특성을 표준화해 수치 계산을 안정적으로 한다.
`StandardScaler`는 학습 평균을 빼고 학습 표준편차로 나누는 변환기다. 검증 입력에도 학습 데이터에서 구한 평균과 표준편차를 사용한다.

```python
polynomial_scaler = StandardScaler()
# 학습 특성으로 평균과 표준편차를 구하고 변환한다.
X_train_poly_scaled = polynomial_scaler.fit_transform(X_train_poly)
# 검증 특성은 학습한 기준으로만 변환한다.
X_val_poly_scaled = polynomial_scaler.transform(X_val_poly)

# 같은 학습 행의 다항 특성을 표준화 전후로 비교한다.
polynomial_columns = polynomial_features.get_feature_names_out()
display(pd.concat({
    "표준화 전": pd.DataFrame(X_train_poly, columns=polynomial_columns, index=X_train.index),
    "표준화 후": pd.DataFrame(X_train_poly_scaled, columns=polynomial_columns, index=X_train.index),
}, axis=1).head().round(3))
```

### 모델 학습과 직선·곡선 비교

`LinearRegression`에 변환한 학습 특성과 몸무게를 전달해 모델을 학습한다.
예측할 때도 다항 특성 생성과 표준화를 거친 입력을 전달한다.

단순 회귀와 다항 회귀는 같은 학습 데이터의 날개 길이와 몸무게를 사용한다. 점은 학습 관측값이며, 두 선은 같은 날개 길이 범위에서 계산한 예측이다.
곡선이 어느 구간에서 직선과 다르게 예측하는지 살펴본다.

```python
polynomial_model = LinearRegression()
polynomial_model.fit(X_train_poly_scaled, y_train)
# 검증 데이터의 몸무게를 예측한다.
polynomial_val_prediction = polynomial_model.predict(X_val_poly_scaled)
print("다항 회귀의 검증 예측 모양:", polynomial_val_prediction.shape)

# 곡선을 그리기 위해 일정한 간격의 날개 길이에서 예측값을 계산한다.
line_poly = polynomial_features.transform(line_X)
line_poly_scaled = polynomial_scaler.transform(line_poly)
polynomial_line_prediction = polynomial_model.predict(line_poly_scaled)
```

### 규제로 계수의 크기 조절하기

### 규제는 무엇인가

다중 선형 회귀는 여러 입력에 각각 계수를 곱해 예측한다. 입력 특성이 서로 비슷하면 큰 양수·음수 계수가 서로 상쇄되며 예측할 수 있고, 학습 데이터가 조금 달라져도 계수가 크게 변할 수 있다.
규제(regularization)는 손실 함수에 계수 크기의 벌점을 더해 학습하는 방법이다. 큰 계수를 억제해 모델을 안정적으로 만들고 과적합을 줄이는 데 도움이 될 수 있다.

```text
학습할 때 최소화하는 값 = 손실 + 규제 강도 × 계수에 주는 벌점
```

계수를 바꾸면 예측 오차와 벌점이 함께 달라진다. 모델은 두 항의 합이 가장 작아지는 계수와 절편을 찾는다.

### 수식에 사용하는 기호

- $n$: 학습 사례 수, $p$: 전처리 후 입력 특성 수
- $y_i$: $i$번째 사례의 실제값, $\hat{y}_i$: 모델의 예측값
- $w_j$: $j$번째 특성에 곱하는 계수
- $\alpha$: 벌점에 곱하는 0 이상의 규제 강도
- $\sum$: 지정한 값들을 모두 더한다는 기호

여기서 $J$는 손실 함수에 규제 벌점을 더한 목적 함수(objective function)이며, 모델은 $J$를 최소화하는 계수와 절편을 찾는다. 다음 식은 scikit-learn의 `Ridge`와 `Lasso`에서 사용하는 기준이다.

### Ridge: 계수의 제곱에 벌점 주기

$$
J_{\mathrm{Ridge}} = \sum_{i=1}^{n}(y_i-\hat{y}_i)^2
+ \alpha\sum_{j=1}^{p}w_j^2
$$

앞 항은 모든 학습 사례의 잔차를 제곱해 더한 값이다. 뒤 항은 계수를 제곱해 더한 벌점이며, L2 규제라고 한다.
계수의 절댓값이 커질수록 제곱 벌점이 빠르게 증가하므로, Ridge는 큰 계수를 억제하고 계수의 전체적인 크기를 줄이는 방향으로 학습한다.

### Lasso: 계수의 절댓값에 벌점 주기

$$
J_{\mathrm{Lasso}} = \frac{1}{2n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
+ \alpha\sum_{j=1}^{p}\lvert w_j\rvert
$$

앞 항은 MSE의 절반이고, 뒤 항은 계수의 절댓값을 더한 벌점이다. 이 벌점을 L1 규제라고 한다.
계수가 0에서 벗어나면 L1 벌점은 그 크기에 비례해 증가한다. 계수를 움직여 줄어드는 예측 오차보다 벌점 증가가 크면, 그 계수는 0에 머물 수 있다. 따라서 Lasso는 일부 계수를 정확히 0으로 만들어 해당 특성의 항을 예측 계산에서 제외할 수 있다.

### 계수에 따른 벌점 비교

계수가 두 개인 경우, 규제 강도를 곱하기 전의 벌점은 다음과 같다.

| 계수 $(w_1, w_2)$ | L2 벌점 $w_1^2+w_2^2$ | L1 벌점 $\lvert w_1\rvert+\lvert w_2\rvert$ |
| --- | --- | --- |
| $(3, -1)$ | $9+1=10$ | $3+1=4$ |
| $(1, -1)$ | $1+1=2$ | $1+1=2$ |

첫 번째 계수를 3에서 1로 줄이면 L2 벌점은 8, L1 벌점은 2 줄어든다. 실제 학습에서는 이때의 예측 오차 변화도 함께 반영한다.

### 규제 강도와 입력 크기

같은 모델에서 $\alpha$가 클수록 계수 벌점의 비중이 커진다. 규제가 너무 강하면 필요한 관계까지 충분히 표현하지 못하는 과소적합이 생길 수 있다.
두 모델은 오차 항의 배율과 벌점 형태가 다르므로, 규제 강도에 따른 변화는 각 모델 안에서 비교한다. 기본 설정에서 절편은 예측값에 포함되며 규제 벌점에서는 제외된다.

입력의 단위가 다르면 계수의 크기도 달라지므로 규제를 적용하기 전에 숫자 특성을 표준화한다. 표준화는 입력의 척도를 맞추는 변환이고, 규제는 모델의 학습 기준에 벌점을 추가하는 방법이다.

### 같은 입력으로 모델 비교하기

날개 길이·부리 길이·관측한 섬으로 몸무게를 예측한다. 숫자 입력을 표준화하고 섬을 원핫 인코딩한 `X_train_processed`, `X_val_processed`를 사용한다.
학습·검증 구간과 전처리 결과를 고정하고 규제가 없는 다중 선형 회귀, Ridge, Lasso를 비교한다.

```python
REGULARIZATION_ALPHAS = [0.1, 10.0, 100.0]
regularization_models = {"multiple": regression_model}
for alpha in REGULARIZATION_ALPHAS:
    # alpha: 규제 강도. 각 모델 안에서 값을 바꾸며 비교한다.
    regularization_models[f"ridge_alpha_{alpha:g}"] = Ridge(alpha=alpha)
    # max_iter: 계수를 구하는 반복 계산의 최대 횟수
    regularization_models[f"lasso_alpha_{alpha:g}"] = Lasso(alpha=alpha, max_iter=100_000)
```

### 오차와 계수 함께 읽기

계수 표는 전처리한 특성별 가중치를 보여준다.
`zero_coefficients`는 정확히 0인 계수의 개수다.

```python
regularization_rows = []
regularization_coefficients = {}

for name, model in regularization_models.items():
    # 입력: (표본 수, 전처리 후 특성 수) 배열, 정답: (표본 수,) Series
    model.fit(X_train_processed, y_train)
    regularization_train_prediction = model.predict(X_train_processed)
    regularization_val_prediction = model.predict(X_val_processed)

    model_results[name] = {
        "model": name,
        "train_RMSE_g": np.sqrt(mean_squared_error(y_train, regularization_train_prediction)),
        "val_RMSE_g": np.sqrt(mean_squared_error(y_val, regularization_val_prediction)),
        "val_MAE_g": mean_absolute_error(y_val, regularization_val_prediction),
        "train_R2": r2_score(y_train, regularization_train_prediction),
        "val_R2": r2_score(y_val, regularization_val_prediction),
    }

    # 규제 비교표에는 0인 계수 개수도 함께 표시한다.
    regularization_row = model_results[name].copy()
    regularization_row["zero_coefficients"] = int(np.count_nonzero(model.coef_ == 0))
    regularization_rows.append(regularization_row)
    regularization_coefficients[name] = model.coef_.copy()  # 특성 순서와 같은 (전처리 후 특성 수,) 배열

regularization_comparison = pd.DataFrame(regularization_rows)

# 모델 이름을 행으로, 전처리 후 특성 이름을 열로 배치한다.
regularization_coefficient_table = pd.DataFrame.from_dict(
    regularization_coefficients,
    orient="index",
    columns=preprocessor.get_feature_names_out(),
)
display(regularization_comparison)
display(regularization_coefficient_table)
```

### 규제 강도에 따른 결과 해석

규제 강도를 높일 때 학습·검증 오차가 함께 커지면 필요한 관계를 충분히 표현하지 못하는 과소적합을 의심할 수 있다.
Lasso가 선택하는 특성은 함께 사용하는 입력과 규제 강도에 따라 달라진다.

### 회귀 모델 비교와 선택

단순 회귀·2차 다항 회귀·3차 다항 회귀·다중 회귀·Ridge·Lasso의 검증 결과를 비교한다.
단순·다항 회귀는 날개 길이만 사용하고, 다중 회귀·Ridge·Lasso는 부리 길이와 섬 정보도 사용한다. 이 두 입력 구성 사이의 성능 차이를 규제만의 효과로 해석하지 않는다.
검증 RMSE가 가장 작은 모델을 선택한다. 값이 같으면 표에 먼저 나온 모델을 사용하며, 테스트 데이터는 선택에 사용하지 않는다.

```python

    "simple": simple_model,

test_inputs.update({name: X_test_multiple for name in regularization_models})
# idxmin: 검증 RMSE가 가장 작은 행의 인덱스를 반환한다.
selected_name = model_comparison.loc[model_comparison["val_RMSE_g"].idxmin(), "model"]
selected_model = models[selected_name]
selected_test_input = test_inputs[selected_name]
print("선택한 모델:", selected_name)
```

### 학습·테스트 오차 해석

학습 오차보다 테스트 오차가 훨씬 크면 과적합을 의심할 수 있다. 두 오차의 차이가 작으면 새 데이터에서도 학습 데이터와 비슷한 성능을 보인 것이다.
다만 두 오차가 모두 클 수도 있으므로, 차이가 작다는 것만으로 충분히 정확한 모델이라고 판단하지 않는다.

### 대화에서 다시 짚은 것

> ➕ **더 알아두기**
>
> wx+b에서 w는 x가 한 단위 증가할 때 예측값이 변하는 양이고 b는 x=0에서의 예측값이다. 04번 본 실습은 펭귄의 몸무게 예측이며 Auto MPG는 마지막 종합 연습문제다. MAE는 오차의 절댓값 평균, MSE는 제곱 평균, RMSE는 MSE의 제곱근이다. R²=1−잔차제곱합/총제곱합으로, 평균 기준보다 예측이 나쁘면 음수가 될 수 있다.
>
> 학습률은 최적화의 한 걸음 크기다. 기울기가 −8이고 학습률이 0.1이면 계수는 0.8 증가한다. alpha는 목적 함수에 더하는 계수 벌점의 비중이다. 계수가 10인 A와 2인 B에 alpha=0.1로 Ridge 벌점을 매기면 10과 0.4다. 설명용 오차가 4와 9라면 벌점 포함 손실은 14와 9.4다. 실제 fit은 벌점이 있는 손실을 최소화하도록 계수를 다시 계산한다. scikit-learn Ridge의 오차 항은 원리 설명에 쓰인 MSE 대신 잔차제곱합이다.
>
> Ridge는 계수의 제곱합을, Lasso는 절댓값의 합을 사용한다. 절댓값은 0에서 기울기가 꺾이므로 Lasso는 일부 계수를 정확히 0으로 만들 수 있다. Ridge는 계수를 전반적으로 줄인다. 단위가 다르면 계수 크기도 달라질 수 있어 규제 전에 스케일링을 고려한다. 르베그 Lᵖ 공간에서는 함수 크기의 p제곱을 적분해 크기를 재며, 이 실습의 유한 계수 벡터에서는 대응하는 합으로 이해할 수 있다.
>
> 다중 선형 회귀는 여러 입력을 사용한다. 다항 회귀는 x², x³ 같은 항으로 곡선을 표현하며 계수에는 선형이다. 무게·마력과 무게²를 쓰면 두 개념을 함께 적용한다. 대화의 가상 검증 RMSE에서 선형 4.2, 다항 3.5, Ridge 3.2, Lasso 3.8이면 RMSE 기준으로 Ridge를 선택한다. 모델과 차수, alpha를 검증에서 선택한 뒤 테스트는 최종 평가에 사용한다. 학습·검증을 합쳐 다시 학습한다면 전처리 기준도 그 데이터에서 다시 구한다. 개념 설명을 마쳤고 펭귄 회귀와 Auto MPG 종합 코드를 실행하는 일은 이후로 미뤘다.
