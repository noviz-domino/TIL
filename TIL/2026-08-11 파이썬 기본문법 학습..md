## 1. 파이썬 변수와 자료형 기초

### 1.1 변수의 개념과 자료형

변수는 데이터를 메모리에 저장하고 이름을 붙여 사용하는 '데이터 바구니'다. 메모리의 특정 주소를 숫자로 직접 외울 수 없기 때문에 이름을 붙여 편리하게 불러오고 값을 바꿔가며 사용한다. 실무에서는 사용자 입력값이나 API 응답 데이터를 임시로 담아두고 가공하거나, 조건문·반복문에 전달할 때 필수적으로 활용한다.

파이썬의 대표적인 기본 자료형(Data Type)은 다음과 같다.

- **숫자형**: 정수(`int`), 실수(`float`)
- **문자열**: `str`
- **불리언**: `bool` (참/거짓인 `True`, `False`)

파이썬은 변수에 값을 넣을 때 타입을 따로 선언하지 않고 **자동으로 타입을 판별**한다. 예를 들어 `x = 10`이라고 선언하면 파이썬이 알아서 정수형(`int`)으로 처리한다.

### 1.2 변수 명명 규칙 (Naming Convention)

1. **사용 가능 문자**: 영문자, 숫자, 언더스코어(`_`)를 조합해서 만든다. (단, 숫자로 시작할 수는 없다.)
2. **대소문자 구분**: `age`와 `Age`는 완전히 다른 변수로 인식된다.
3. **예약어 사용 불가**: `if`, `for`, `class`처럼 파이썬 내부 키워드는 변수 이름으로 사용할 수 없다.

실무에서는 여러 단어를 조합할 때 `user_name`처럼 단어 사이에 언더스코어를 붙이는 **스네이크 케이스(snake_case)** 표기법을 표준으로 사용한다.

### 1.3 변수의 사용과 동적 타이핑 (Dynamic Typing)

```python
# 변수 선언과 값 변경
user_count = 5         # 변수 생성
user_count = user_count + 1  # 기존 값(5)에 1을 더해 6으로 변경

# 변수끼리의 연산
price = 1000
quantity = 3
total_price = price * quantity  # total_price는 3000
```

파이썬 변수의 주요 특징 중 하나는 '동적 타이핑(Dynamic Typing)'이다. 변수에 처음에 숫자(`100`)를 넣었다가 나중에 문자열(`"백"`)로 바꿔 넣어도 에러가 발생하지 않는다. 유연해서 편리하지만, 원치 않는 데이터 타입으로 바뀌어 버그가 생길 수 있으므로 변수의 역할을 명확히 유지하는 것이 좋다.

> ➕ **더 알아두기**
> 8월 14일에 배운 "함수 매개변수에 타입을 지정하지 않는 이유"와 완전히 같은 원리다. 그때는 함수의 입력값 기준이었고, 여기서는 변수 자체 기준이라는 차이만 있다. 둘 다 파이썬이 **런타임에 값을 보고 타입을 정한다**는 동적 타이핑에서 나온다.

### 1.4 변수의 타입 확인: `type()`과 `isinstance()`

변수의 데이터 타입을 확인하고 싶을 때는 파이썬 내장 함수인 `type()`을 사용한다. `type(변수명)`을 실행하면 해당 변수에 담긴 값의 자료형(예: `<class 'int'>`, `<class 'str'>`)을 바로 반환한다. 실무에서는 외부 API나 데이터베이스에서 데이터를 받아왔을 때, 예상한 타입이 맞는지 검증하고 타입 오류(`TypeError`)를 방지하기 위해 자주 사용한다.

```python
# 변수 선언
age = 20
name = "Alice"
scores = [90, 85, 100]

# 1. type() 사용 예시
print(type(age))     # 출력: <class 'int'>
print(type(name))    # 출력: <class 'str'>
print(type(scores))  # 출력: <class 'list'>
```

`isinstance()`는 **`isinstance(확인할_변수, 검사할_타입)`** 형태로 사용하며, 변수가 검사할 타입이 맞으면 `True`, 아니면 `False`를 반환한다. 튜플 형태로 여러 타입을 전달하여 검사할 수도 있다.

```python
# isinstance() 기본 사용법
age = 20
print(isinstance(age, int))  # True

# 여러 타입 중 하나인지 검사 (튜플로 전달)
value = 3.14
print(isinstance(value, (int, float)))  # True (정수나 실수 중 하나이면 True)

# 실무 조건문 검증 예시
if isinstance(age, int):
    print("age는 정수형이 맞습니다.")
```

실무에서는 사용자 입력값이나 API 통신 데이터처럼 "원하는 타입의 데이터가 들어왔는지 검증"할 때 `isinstance()`를 주로 사용한다. `type(x) == int`보다 `isinstance()`를 사용하는 이유는 상속 관계를 가지는 객체까지 정확하게 판별해 주기 때문이다.

## 2. 조건문과 입출력 기초

### 2.1 조건문의 개념

조건문은 작성한 프로그램이 특정 조건의 참(`True`) 또는 거짓(`False`) 여부에 따라 **서로 다른 코드를 실행하도록 흐름을 제어하는 문법**이다. 파이썬에서는 `if`, `elif`, `else` 키워드를 사용한다.

컴퓨터가 상황에 맞춰 스스로 판단하게 만들기 위해 사용하며, 실무에서는 사용자의 권한 체크, 입력값 검증, 비즈니스 로직(Business Logic) 처리 등에 필수적으로 사용된다.

### 2.2 사용자 입력받기: `input()`

사용자에게 직접 값을 받아오는 내장 함수는 `input()`이다.

```python
user_input = input("값을 입력하세요: ")
```

`input()`을 사용할 때 가장 주의해야 할 점은 **입력받은 데이터가 항상 문자열(`str`) 타입으로 반환**된다는 것이다. 따라서 숫자로 계산하거나 크기를 비교하려면 `int(input())`이나 `float(input())`처럼 명시적으로 형변환(Type Casting)을 해주어야 한다. 실무에서는 이렇게 입력받은 데이터가 조건문(`if`)의 판단 기준으로 연결되어 활용되는 경우가 많다.

### 2.3 출력과 디버깅: `print()`

출력을 담당하는 내장 함수는 `print()`다. `print("내용")`처럼 사용하면 화면(터미널)에 원하는 결과나 변수 값을 보여준다. 실무나 학습 중에는 내가 만든 코드나 변수에 어떤 값이 들어가 있는지 **실시간으로 확인하고 버그를 찾는(디버깅) 가장 기본적인 도구**로 사용된다.

`input()`으로 값을 받고, 조건문(`if`)으로 판단한 뒤, 그 결과를 `print()`로 출력하는 형태가 파이썬 프로그램의 가장 기본적인 기초 흐름이다.

### 2.4 조건문의 기본 구조와 사용법

파이썬 조건문의 기본 구조는 `if`, `elif`(else if의 줄임말), `else`로 구성된다.

```python
score = int(input("점수를 입력하세요: "))

if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
else:
    print("F학점")
```

조건문 작성 시 문장의 끝에 `:`(콜론)을 붙여야 하며, 조건에 속하는 코드 블록은 들여쓰기(Indent, 공백 4칸)를 필수적으로 맞춰야 한다. 실무에서는 여러 조건이 복잡하게 얽힐 때 `and`, `or`, `not` 같은 논리 연산자와 함께 사용하여 사용자의 권한이나 데이터의 유효성을 검증할 때 자주 사용한다.

**⚠️ 헷갈리기 쉬운 점**

- `input()`으로 받은 데이터는 숫자를 입력하더라도 모두 문자열(`str`) 타입이 된다. 숫자로 비교하려면 반드시 `int()` 등으로 형변환을 거쳐야 조건문에서 크기 비교 연산이 정상 작동한다.
- 조건문 작성 시 `if`, `elif`, `else` 줄 끝의 콜론(`:`)을 누락하거나, 아래 블록의 들여쓰기(Indent)를 맞추지 않으면 `SyntaxError` 또는 `IndentationError`가 발생한다.
