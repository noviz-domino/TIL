### AI 에이전트 (AI Agent)

- **개념**: 단순 질문 답변을 넘어, 스스로 목표를 달성하기 위해 판단하고 외부 도구(검색, 코드 실행, API 등)를 사용해 작업을 수행하는 AI 시스템.
    
      
    
- **AI 에이전트 엔지니어의 역할**: 에이전트의 흐름(Workflow)을 설계하고, LLM과 외부 데이터베이스 및 도구를 연결하며, 의도대로 동작하도록 정밀하게 제어하는 백엔드/AI 개발자.
    
      
    
- **핵심 요소**: LLM 성능 자체보다 **상태 관리(State Management)** 및 **외부 도구 활용(Tool Calling)** 설계가 중요함.
    
      
    

### 프롬프트 기법 (Prompting Techniques)

- **제로샷 (Zero-shot)**: 모델에게 예시를 주지 않고 바로 질문하는 기법.
    
      
    
- **퓨샷 (Few-shot)**: 몇 가지 입출력 예시를 프롬프트에 미리 보여주어 답변 형식이나 패턴을 유도하는 기법.
    
      
    - **원샷 (One-shot)**: 예시를 1개만 제공하는 방식.
        
          
        
    - **실무 활용**: LLM의 출력을 특정 형식(예: JSON)으로 고정하거나 복잡한 분류 작업을 지시할 때 필수적으로 사용함.
        
          
        
    - **LangChain 연동**: `FewShotPromptTemplate` 클래스를 통해 퓨샷 예시를 동적으로 관리하고 삽입 가능.
        
          
        

### 프롬프트 체이닝 (Prompt Chaining)

- **개념**: 하나의 복잡한 작업을 여러 개의 작은 프롬프트 단계로 쪼개고, 앞 단계의 출력 결과를 다음 단계의 입력으로 연결하는 기법.
    
      
    
- **목적**: 한 번의 요청으로 인한 환각(Hallucination) 현상이나 지시사항 누락을 방지하고 정확도를 높임.
    
      
    
- **실무 활용**: 긴 보고서 작성, 코드 생성 및 검증, 복잡한 데이터 추출 프로세스 자동화 등에 사용.
    
      
    
- **LangChain과의 관계**: LangChain이라는 이름 자체가 이러한 프롬프트 체이닝을 코드 단에서 쉽게 구현해 준다는 의미에서 유래함.
    
      
    

### 루브릭 (Rubric)

- **개념**: AI의 답변이나 수행 결과를 정량적으로 평가하고 검증하기 위해 세운 명확한 평가 기준표.
    
      
    
- **실무 활용**: LLM의 출력을 자동 평가(LLM-as-a-Judge)하거나, 에이전트의 결과물이 사용자에게 전달되기 전 가이드라인(Guardrails)을 통과했는지 검증할 때 기준이 됨.
    
      
    
- **관련 도구**: LangChain/LangGraph 생태계에서는 **Ragas**, **LangSmith** 등의 모니터링/평가 도구와 함께 사용함.
    
      
    

### LangChain과 관련 패키지

- **LangChain 개념**: LLM 기반 애플리케이션을 빠르게 개발할 수 있도록 프롬프트 관리, RAG(외부 데이터 연결), 메모리, API 연동 등을 표준 인터페이스로 제공하는 프레임워크.
    
      
    
- **주요 구성 요소**: Prompts, Models, Indexes/VectorStores, Chains.
    
      
    
- **LangGraph와의 차이점**:
    
      
    - **LangChain**: 일직선 형태의 단순 체인(Chain) 및 프롬프트 체이닝 구현에 적합.
        
          
        
    - **LangGraph**: 조건 분기(If-Else) 및 순환 제어(Loop)가 필요한 복잡한 에이전트의 흐름을 그래프 구조로 제어.
        
          
        

#### 주요 설치 패키지 역할

Bash

```
pip install google-genai langchain langchain-google-genai langchain-community
```

- `google-genai`: 구글 Gemini 모델을 다루기 위한 최신 공식 SDK.
    
      
    
- `langchain`: 프롬프트, 체인, 에이전트 등 LangChain의 핵심 표준 기능이 담긴 본체.
    
      
    
- `langchain-google-genai`: LangChain 내에서 구글 Gemini 모델을 편리하게 연동하는 전용 패키지.
    
      
    
- `langchain-community`: 써드파티 도구, 다양한 데이터베이스, 커뮤니티 제작 연결 모듈이 모여있는 확장팩 라이브러리.
    
      
    

### ⚠️ 헷갈리기 쉬운 점

- **패키지 파편화 구조**: 과거에는 `langchain` 라이브러 하나에 모든 기능이 들어있었으나, 라이브러리가 무거워짐에 따라 현재는 Core 본체와 각 LLM/도구별 연동 패키지(`langchain-google-genai`, `langchain-community` 등)로 분리되어 관리됨.
    
      
    
- **구글 SDK 버전 차이**: 기존 `google-generativeai`에서 최신 `google-genai` 표준 패키지로 세대교체가 진행 중이므로 패키지명을 정확히 구분하여 설치해야 함.
