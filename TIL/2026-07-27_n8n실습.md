```plain text
# 🚀 n8n & 구글 폼 기반 설문 응답 자동화 정리

## 📌 1. 전체 프로세스 개요
3개의 개별 구글 폼(1번: 회원 정보, 2번: 취미/음식, 3번: 영화) 응답을 **구글 시트(통합 시트) 하나로 수집 및 업데이트**하고, 조건에 따라 안내 메일을 발송하는 자동화 워크플로우.

```text
[폼 1/2/3 트리거]
       ↓
[Skip empty rows] (빈 행 제거 / 예외 처리)
       ↓
[Append or Update row] (통합 시트 업데이트)
       ↓
[Get row(s) in sheet] ➔ [If 노드] ➔ [Gmail 발송]
```

---

## 🛠️ 2. 핵심 구현 및 노드별 설정

### ① 트리거 예외 처리 (Skip empty rows 노드)

  * 목적: 구글 시트에서 발생할 수 있는 데이터 없는 빈 행(Blank Row)을 미리 걸러냄.
  * 설정 (Filter 노드):
    * Left Value: {{ $json['이메일 주소'] }}
    * Condition: is not empty
  * 필요성: 구글 시트에 빈 줄이 수집되면 매칭 기준값(이메일 주소)이 비어 있어 후속 노드에서 The 'Column to Match On' parameter is required 에러가 발생함.
### ② 통합 시트 데이터 업데이트 (Append or Update Row)

  * 1번 폼 (최초 제출):
    * Operation: Append Row
    * 1번 폼 제출 시 통합 시트에 새로운 행(Row)을 최초 생성.
  * 2번 & 3번 폼 (추가 제출):
    * Operation: Append or Update Row
    * Column to match on: 이메일 주소
    * 1번 폼을 통해 시트에 미리 등록된 이메일을 찾아 해당 사용자의 위치에 취미/음식/영화 정보 추가 기록.
### ③ 1번 폼 미제출자 예외 처리 (검문소)

  * 문제 상황: 1번 폼(이름/이메일)을 쓰지 않고 2,3번 폼을 먼저 쓴 사용자의 경우 메일 발송 금지 처리 필요.
  * 해결 방법:
    1. Get row(s) in sheet 노드로 통합 시트 조회.
    1. If 노드에서 시트 내 이름 항목 존재 여부 확인 ({{ $json['이름'] }} is not empty).
    1. 1번 폼을 쓰지 않은 사용자는 이름 데이터가 없으므로 If 노드에서 False로 판정되어 메일 발송 없이 자동 종료.

## 💡 3. 트러블슈팅 (주요 에러 및 원인 정리)

### ❓ Issue 1: The 'Column to Match On' parameter is required 에러 발생

  * 원인:
    1. Append or Update Row 사용 시 매칭 기준(Column to match on) 열이 UI상에서 파라미터 등록 미완료 상태였음.
    1. 트리거를 통해 빈 줄(Blank Row, 이메일이 빈값인 행) 데이터가 들어오면서 매칭 대상 값을 찾지 못함.
  * 해결:
    * 트리거 바로 뒤에 Skip empty rows (Filter 노드)를 추가하여 이메일이 있는 정상 데이터만 통과되도록 조치.
### ❓ Issue 2: 개별 응답 시트에 상단 빈 공간(행)이 생기는 현상

  * 원인:
    * 구글 폼 연동 시트는 데이터 추가 시 아래쪽에 '새로운 행을 물리적으로 삽입(Insert)'함.
    * 키보드의 Delete 키는 셀 내부 텍스트만 삭제할 뿐 행 자체를 지우지 않으므로 구글 폼은 빈 행 아래쪽에 응답을 계속 쌓음.
  * 해결:
    * 구글 시트에서 빈 행 번호를 마우스 우클릭 ➔ 행 삭제를 실행해야 물리적으로 아래 행들이 위로 바짝 당겨짐.
