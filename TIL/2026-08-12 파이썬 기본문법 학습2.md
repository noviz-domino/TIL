## 리스트(List)의 개념과 활용

> 📍 정리 #1
> 
> 🏷️ 키워드: list, container, index, append
> 
>   

### 리스트란?

- 여러 개의 데이터를 순서대로 담을 수 있는 컨테이너 자료형입니다.
    
      
    
- 변수 하나에 값을 여러 개 묶어서 관리하며, 대괄호(`[]`)를 사용해서 선언합니다.
    
      
    

### 기본 사용법

- **생성 및 조회:** `items = ["사과", "바나나"]`로 생성하고, `items[0]`처럼 인덱스로 접근합니다.
    
      
    
- **추가:** `items.append("포도")`를 사용해 맨 뒤에 데이터를 추가합니다.
    
      
    
- **수정:** `items[1] = "망고"`처럼 특정 위치의 값을 변경할 수 있습니다.
    
      
    
- **삭제:** `items.remove("사과")`나 `del items[0]`으로 제거합니다.
    
      
    

### 인덱스 접근과 특징

- 인덱스(Index)는 0부터 시작하는 숫자로, 이를 통해 각 요소에 바로 접근할 수 있습니다.
    
      
    
- 컴퓨터 메모리에 데이터가 순서대로 배치되기 때문에 인덱스 번호만 알면 위치를 바로 찾아갈 수 있습니다.
    
      
    
- **음수 인덱스:** `-1` 같은 음수 인덱스를 사용하면 맨 마지막 데이터에 바로 접근할 수 있습니다 (`items[-1]`).
    
      
    

### 왜 쓰며 실무에서 언제 만날까?

- 데이터가 1개, 2개일 땐 변수를 따로 만들어도 되지만, 데이터가 많아지면 개별 변수로 관리할 수 없기 때문에 하나의 묶음(리스트)으로 다루게 됩니다.
    
      
    
- 실무에서는 쇼핑몰 장바구니 목록, 게시판 글 목록, 회원 이메일 리스트, API response 데이터 등 동일한 형태의 데이터 집합을 다루거나 반복문(`for`)과 함께 돌릴 때 사용합니다.
    
      
    
- 게시글 목록 중 첫 번째 글(`posts[0]`)을 가져오거나, 최신 가입자 N명처럼 특정 순서의 데이터를 뽑아낼 때도 활용됩니다.


## 반복문 for와 range(), len()의 활용

> 📍 정리 #2
> 
> 🏷️ 키워드: for, range, len, loop, list
> 
> 🔗 이어짐: 정리 #1 리스트(List)의 개념과 활용
> 
>   

### 반복문 for란?

- 리스트 같은 컨테이너 자료형에 들어있는 요소들을 하나씩 꺼내서 반복 처리하는 반복문이야.
    
      
    
- 데이터가 100개든 1,000개든 일일이 코드를 적지 않고 한 번에 처리하기 위해 사용해.
    
      
    
- 실무에서는 게시글 목록 전체를 화면에 그릴 때, 모든 회원에게 안내 메일을 발송할 때, 또는 조건에 맞는 데이터만 걸러낼 때 필수로 쓰여.
    
      
    

### for문 활용 패턴 (리스트 직접 순회 vs range)

`for`문은 리스트 자체를 직접 돌릴 수도 있고, `range()`로 숫자를 만들어서 돌릴 수도 있어.

  

1. **리스트 직접 순회 (`for item in items`)**
    
      
    
    - 리스트 안의 **값 자체**가 필요할 때 사용해. 코드가 깔끔해서 제일 많이 쓰여.
        
          
        
    
    Python
    
    ```
    users = ["민석", "철수", "영희"]
    
    for user in users:
        print(f"{user}님에게 메일 발송")
    ```
    
2. **`range()`와 `len()` 활용 (`for i in range(len(items))`)**
    
      
    
    - 몇 번째인지 인덱스 번호(위치)가 직접 필요하거나, 단순히 N번 반복해야 할 때 써.
        
          
        
    - `len()`은 리스트의 전체 개수(길이)를 알려주는 함수로, `range(len(items))` 형태로 조합하면 리스트의 처음부터 끝까지 인덱스 번호를 생성할 수 있어.
        
          
        
    - 실무에서는 리스트 전체 개수를 모를 때 `len()`을 써서 "리스트 길이만큼 반복해라"라고 지시하거나, "3번째 요소마다 처리", "두 리스트의 같은 위치 값을 비교"할 때 활용해.
        
          
        
    
    Python
    
    ```
    users = ["민석", "철수", "영희"]
    
    for i in range(len(users)):
        print(f"{i + 1}등: {users[i]}")  # 몇 번째인지 순서(i)와 함께 출력
    ```
    

### ⚠️ 헷갈리기 쉬운 점

- `range(len(items))`를 사용할 때 `len()`이 반환하는 값은 '전체 개수'이지만, 인덱스는 `0`부터 시작하기 때문에 `range()`가 생성하는 마지막 인덱스 번호는 `len(items) - 1`이 돼.
    
      
    
- 값만 필요할 때는 리스트를 직접 순회하는 것이 훨씬 가독성이 좋고, 순서(인덱스)가 함께 필요한 경우에만 `range()`와 `len()`을 조합하는 것이 좋아.


## enumerate() 함수를 활용한 리스트 순회

> 📍 정리 #3
> 
> 🏷️ 키워드: enumerate, for, list, index, loop
> 
> 🔗 이어짐: 정리 #2 반복문 for와 range(), len()의 활용
> 
>   

### enumerate() 함수란?

- 리스트를 `for`문으로 돌릴 때 **인덱스(순서)와 값(데이터) 2개를 동시에** 꺼내주는 함수야.
    
      
    
- `range(len(items))`를 써서 `items[i]` 형태로 요소에 다시 접근할 필요 없이, 인덱스와 값을 한 번에 변수로 받아올 수 있어 코드가 훨씬 깔끔해져.
    
      
    

### 기본 사용법 및 코드 예시

Python

```
users = ["민석", "철수", "영희"]

for i, user in enumerate(users):
    print(f"{i + 1}등: {user}")
```

### 왜 쓰며 실무에서 언제 만날까?

- 순서(위치 정보)와 데이터 값이 모두 필요한 상황에서 가독성을 대폭 높여줘.
    
      
    
- 실무에서는 화면에 **게시글 번호와 제목을 함께 표시할 때**, 목록의 **특정 위치(예: 첫 번째 또는 마지막) 데이터만 다르게 처리할 때** `range(len())` 대신 `enumerate()`를 훨씬 더 선호하고 자주 써.

## 문자열 자릿수 채우기: zfill()과 rjust()

> 📍 정리 #4
> 
> 🏷️ 키워드: zfill, rjust, string, format, padding
> 
>   

### zfill() 메서드

- 문자열(String)의 앞쪽에 `0`을 채워서 지정한 전체 길이만큼 맞춰주는 메서드야 (Zero fill).
    
      
    
- **괄호 안 필수 인자:** 목표로 하는 전체 자릿수(길이)를 숫자로 반드시 지정해야 해. 인자를 비워두면 `TypeError`가 발생해.
    
      
    
- **음수(-) 처리 특성:** 음수 부호가 포함된 경우 부호를 유지하면서 채워줘 (예: `"-5".zfill(3)` $\rightarrow$ `"-05"`).
    
      
    

Python

```
num = "7"
print(num.zfill(3))   # "007"

negative = "-5"
print(negative.zfill(3))  # "-05"
```

### rjust() 메서드

- 문자열을 **오른쪽으로 정렬**하고, 남는 왼쪽 공간을 지정한 문자로 채워주는 메서드야 (Right Justify).
    
      
    
- `zfill()`과 달리 `0`뿐만 아니라 공백(' '), 별표('*'), 대시('-') 등 원하는 문자를 지정할 수 있어. 문자를 생략하면 기본 공백으로 채워져.
    
      
    

Python

```
text = "5"
print(text.rjust(3, "0"))  # "005"
print(text.rjust(5, "*"))  # "***5"
print(text.rjust(5))       # "    5"
```

### zfill() vs rjust() 차이점 및 활용

|**구분**|**zfill()**|**rjust()**|
|---|---|---|
|**채울 문자**|무조건 숫자 `0`|공백, 특수문자 등 지정 가능|
|**음수 처리**|부호 유지 (`"-5"` $\rightarrow$ `"-05"`)|단순 왼쪽 채우기 (`"-5"` $\rightarrow$ `"0-5"` 깨짐)|
|**주요 용도**|날짜/시간 자릿수 맞추기, 고유 ID/주문번호 생성|영수증/출력 화면 정렬, 비밀번호 마스킹|

### ⚠️ 헷갈리기 쉬운 점

- `zfill()`의 괄호 안에 들어가는 숫자는 '추가할 0의 개수'가 아니라 '최종 결과물의 전체 길이'야.
    
      
    
- 음수 형식의 문자열에 자릿수를 채울 때는 `rjust()`를 쓰면 `0-5`처럼 숫자가 깨지므로 반드시 `zfill()`을 써야 해.



## f-string(포맷 문자열)의 개념과 활용

> 📍 정리 #5
> 
> 🏷️ 키워드: f-string, format, string, expression, function
> 
> 🔗 이어짐: 정리 #4 문자열 자릿수 채우기: zfill()과 rjust()
> 
>   

### f-string이란?

- 문자열 따옴표 앞에 `f` 또는 `F`를 붙이고, `{}`(중괄호) 안에 변수나 표현식을 넣어서 문자열을 동적으로 생성하는 포맷팅 문법이야.
    
      
    
- 기존의 `+` 연산자로 문자열을 이어붙이거나 `%`, `.format()`을 쓰던 방식보다 가독성이 뛰어나고 작성하기도 쉬워 파이썬 standard로 사용돼.
    
      
    

### 중괄호 `{}` 안에 들어갈 수 있는 것들

중괄호 안에는 단순 변수명뿐만 아니라 파이썬의 다양한 표현식(Expression)을 직접 넣을 수 있어.

  

1. **변수 및 사칙연산**
    
      
    
    Python
    
    ```
    price = 1000
    count = 3
    print(f"총 금액: {price * count}원")  # 총 금액: 3000원
    ```
    
2. **리스트 / 딕셔너리 접근 및 내장/사용자 정의 함수 호출**
    
      
    
    Python
    
    ```
    def get_grade(score):
        return "A등급" if score >= 90 else "B등급"
    
    user = {"name": "민석", "score": 92}
    print(f"{user['name']}님의 성적은 {get_grade(user['score'])}입니다.")
    # 출력: 민석님의 성적은 A등급입니다.
    ```
    
3. **삼항 연산자 (조건문)**
    
      
    
    Python
    
    ```
    score = 85
    print(f"결과: {'합격' if score >= 80 else '불합격'}")
    ```
    
4. **자릿수 및 서식 지정 (Format Specifier)**
    
      
    
    Python
    
    ```
    num = 7
    price = 1000000
    print(f"자릿수 맞추기: {num:03d}")  # 007 (zfill과 유사)
    print(f"천 단위 쉼표: {price:,}원")  # 1,000,000원
    ```
    

### 왜 쓰며 실무에서 언제 만날까?

- 실무에서는 사용자 이름을 넣은 **동적 알림톡/메일 문구 생성**, **DB 조회를 위한 SQL 쿼리 작성**, **API 요청 URL 조합**, **로그(Log) 메시지 출력** 등에 필수적으로 사용돼.
    
      
    

### ⚠️ 헷갈리기 쉬운 점

- 딕셔너리 키(Key)에 접근할 때 f-string 감싸는 따옴표와 딕셔너리 키의 따옴표가 같으면 문법 에러가 발생하므로, 서로 다른 따옴표를 써야 해 (예: `f"{user['name']}"`).
    
      
    
- 중괄호 안에서 함수를 호출할 때는 반드시 **반환값(return)이 있는 함수**여야 문자열에 정상적으로 꽂히게 돼. 반환값이 없는(`None`) 함수를 넣으면 `None`이 출력돼.

## 음의 무한대(float('-inf'))와 양의 무한대(float('inf'))

> 📍 정리 #6
> 
> 🏷️ 키워드: inf, -inf, float, min, max, algorithm
> 
> 🔗 이어짐: 정리 #2 반복문 for와 range(), len()의 활용
> 
>   

### concept

- **`float('-inf')`**: 음의 무한대(Negative Infinity). 그 어떤 실수 값보다도 작음.
    
      
    
- **`float('inf')`**: 양의 무한대(Positive Infinity). 그 어떤 실수 값보다도 큼.
    
      
    
- 파이썬에서는 무한대 전용 숫자가 없기 때문에, `float()` 함수에 문자열 키워드 `'-inf'` / `'inf'`를 인자로 넣어 실수형(`float`) 데이터로 변환해 사용함.
    
      
    

### 왜 쓰며 언제 만날까?

- **최댓값(Max) 구하기**: 초기 기준값을 `float('-inf')`로 설정하면 첫 번째로 비교하는 숫자가 무엇이든 무조건 더 크기 때문에 초기값 갱신이 안전하게 이루어짐.
    
      
    
- **최솟값(Min) 구하기**: 초기 기준값을 `float('inf')`로 설정하면 첫 번째로 비교하는 숫자가 무엇이든 무조건 더 작기 때문에 최솟값을 찾기 유리함.
    
      
    
- **최단 경로 / 최적화 알고리즘**: 그래프 탐색(다익스트라 등)에서 아직 방문하지 않은 노드의 거리를 초기화할 때 사용함.
    
      
    

### 코드 예시

Python

```
scores = [10, 50, -5, 30]

# 1. 최댓값 찾기 (초기값: -inf)
max_val = float('-inf')
for score in scores:
    if score > max_val:
        max_val = score

# 2. 최솟값 찾기 (초기값: inf)
min_val = float('inf')
for score in scores:
    if score < min_val:
        min_val = score

print(f"최댓값: {max_val}, 최솟값: {min_val}")  # 최댓값: 50, 최솟값: -5
```

### ⚠️ 헷갈리기 쉬운 점

- `float('-inf')` 생성 시 따옴표를 붙이는 이유는 문자열 타입이 되어서가 아니라, `float()` 변환 함수에 매개변수로 지정된 키워드일 뿐임. 최종 타입은 `float`(실수형 숫자)임.
    
      
    
- 무한대에 임의의 숫자를 더하거나 빼도 여전히 무한대임 (`float('inf') + 10000` $\rightarrow$ `inf`).
